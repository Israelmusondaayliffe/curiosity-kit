# Source notes

ProofLoop is independently authored from the current private originals' useful functions and selected public methods. Sources are provenance and comparison material, not runtime dependencies. Donor scripts, hooks, setup instructions and model/provider choices are not activated by reading them.

## Originals

Earlier ProofLoop editions supplied the capability baseline. Three modes are preserved locally: bounded Run, selected Memory Review and read-only Audit. Contract/record validation, canonical identity, redaction, conflict detection, action-policy checks, supplied-case comparison and neutral transfer remain functional responsibilities. Duplicated helper copies and wrappers are consolidated; the original supplied actual-versus-expected comparison is not called an executed regression suite.

Original prose described budgets, pinned evidence and guarded learning, while original code did not supply a run ledger, result aggregator or lifecycle writer. Positive timeout values were not enforced. Validation, transfer access and activation metadata also needed repair. These are static source findings; no source-test execution or original model outcome was inferred. Later candidate checks establish only their recorded environment and cases.

Original contributions are licensed under the package-root MIT LICENSE; third-party material retains its stated terms. Licensing does not establish new execution evidence.

## Selected donor methods

- [Pstack/Potato](https://github.com/cursor/plugins/tree/ccb5507cec1546dc88135c1139c811e6c59115ba/pstack): actual mode, verification-map and maintenance methods, meaningful behavior tests, failed-premise revision, evaluation/review, reflection and evidence trails. Adopt observable actions/results and useful local methods. Do not import its broad external-action policy, provider roles, mandatory fan-out, watchers, setup or automatic backlog updates.
- [Matt Pocock](https://github.com/mattpocock/skills/tree/b0618bc436ad893b3c5e84e55fba86586d34a404): actual code review, TDD/tests/mocking, diagnosis, research, retro and writing-for-agents resources. Keep spec and standards judgments distinct, test the real subject against independent expectations, inspect existing mechanisms before adding rules and load branch-specific resources. No setup or issue-tracker prerequisite is inherited.
- [Gstack](https://github.com/garrytan/gstack/tree/b357b503780f7f06b8eaa01c4940abac54de7f2d): review/QA capture, required-evidence aggregation, deadline and judge-control methods. Adopt artifact-bound observations, final unchanged review, incomplete-result accounting and adversarial controls. Do not copy its runtime, global state, provider calls, eventually-allow-red gate or caller-supplied annotation as proof. Its inspected judge report and runner used different aggregation descriptions; no borrowed calibration claim follows.
- [Ponytail](https://github.com/DietrichGebert/ponytail/tree/9cc65d03aa2da1db7121b912d03596409ee340b8): main/review methods and MIT license read. The adaptation follows a simplicity-first method: need first, reuse, native platform, stdlib, installed dependency, smallest complete correct change. Simplicity applies to tests/research/support as well as code; it does not remove trust-boundary checks or requested behavior. No Ponytail runtime installation is required.

Selected methods informed this adaptation, not whole-repository execution. Public method prose and machinery were not transplanted. Substantial future reuse of licensed bytes requires retaining the applicable license notice.
