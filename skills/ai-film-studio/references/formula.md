# Film prompt formula

The project owns its formula. Carry its approved constants into the output unchanged. The shipped compiler supports exact descriptors and an ordered set of these blocks; it rejects unsupported policies rather than approximating them. A creative exception must be settled before compiling.

1. Scene context: exact active character count and the current shot's purpose.
2. References: only active tags, identities/states/versions, each with its role and descriptor.
3. Location map: the scene's shared geography, camera side and reverse-angle rule.
4. First frame: each visible character/prop, landmark-relative position, distance, gaze or orientation.
5. Format: continuous take or a deliberately described cut sequence.
6. Optics: framing, depth and portrait/spatial outcome, not prestige camera labels.
7. Camera: position/motion motivated by the shot's purpose.
8. Action: feasible timed beats with visible end conditions and camera behaviour.
9. Physics: contact, weight and object relationships that protect the scene.
10. Lighting: one motivated principal source under this formula.
11. Audio: locked voice, exact quoted line, action, reaction; only those lines spoken, remaining cast silent; diegetic SFX, music reserved for post.
12. Acting: observable scene adaptation for each active character.
13. Style: the exact project constant.
14. Quality: concrete intended qualities relevant to this shot.
15. Constraints: positive conditions tied to known failure risks.
16. Technical closing information, last.

The location reference informs geography, not inherited composition, camera angle or colour. A target's file labels map to the project tags; labels do not upload files. Active cast count counts declared character assets. A crowd needs an explicit headcount and a manual count review; one crowd asset is not automatically one person.

Before drafting, reduce input to this shot's active facts. Check collision risks: stale tag, wrong state, reference controlling the wrong property, physically overloaded beat, unmotivated second source, missing speaker, contradictory camera side. Assemble the blocks, then inspect the actual result. Do not conduct a compulsory long interview for an already approved bible.

Use short present-tense action with concrete verbs. Keep spoken text only in audio and preserve exact fragments/language. The compiler rejects quoted dialogue in action; it cannot understand every unquoted paraphrase. Age details and unsafe or unhelpful terms require a declared target policy; do not strip a person's identity facts silently. No universal ban-word dictionary or fixed prompt length is imposed. A safety restriction cannot be bypassed through euphemisms.

The source-inspired default keeps performance and geography explicit while allowing project choices. The roughly one-second establishing view, no camera-directed gaze unless requested, restrained beat length and isolated edit discipline are judgment defaults. Respect an intentional alternative and document it. If the compiled subset cannot express a necessary mode, write the full mode-specific prompt through its local playbook and disclose that its checks are manual.

## Mechanical versus craft evidence

The script checks source references/versions, state transitions, block order, exact constants, timed interval coverage, declared occupants, roles, silence, one-light structure and exact output fidelity. It detects planted changes to emitted files. Those are not pixel or story judgments. Human/agent review still tests dramatic effect, implicit contradictions, motion plausibility and actual image/audio evidence. An allowed-looking field can contain a bad direction; do not approve it merely because it parses.
