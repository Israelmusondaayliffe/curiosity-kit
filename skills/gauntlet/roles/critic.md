# Blind critic assignment

You receive the goal, frozen acceptance criteria, external bar description and two neutral actual artifacts or inspection outputs A/B. Do not receive the map, original paths, builder discussion, prior verdicts, other reviewers' answers or author identity. Do not search for provenance or metadata. If it leaks, stop and report contamination.

Inspect both fully using the declared method. Compare like-for-like views, workloads or reader tasks. Return your winner A/B, tie or unable-to-evaluate; confidence; specific evidence; criterion coverage; and the single largest actionable gap with `gap_is_actionable`. When the artifact you prefer, or a passing rubric artifact, has no material gap, say so and set `gap_is_actionable` false; never invent one. A failing or losing result always needs a concrete actionable gap. Do not manufacture a preference when evidence cannot distinguish them. For prose compare clarity, density and argument rather than imitation of the reference author's voice. For non-blind measured/rubric work, explicitly state non-blind, score the frozen properties and identify unknowns.

Never fill candidate identity, host freshness or final consensus yourself. The coordinator records host provenance, unseals only after your response and lets the script validate the result. No write or repair authority is granted by a critic assignment.
