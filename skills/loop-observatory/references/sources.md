# Source lineage and method boundaries

## Original capability

This skill adapts the original private Loop Observatory editions.

The preserved capabilities are explicit source registration, bounded ingestion, duplicate handling, normalization, JSON/Markdown reporting, conditional no-new-result behavior, judge/human calibration and owner repair boundaries. The original router, three specialist methods and three role briefs are now complete local procedures behind one model-neutral front door. No sibling installation is required.

Intentional corrections include authoritative producer-specific field extraction, blocked/nonterminal semantics, current-versus-history counting, source/revision/attempt identity, explicit judgment bindings, finite typed measurements and coverage-qualified costs. The old cost-per-accepted-result name concealed an accepted-only mean; the current method names distinct metrics. Recursive first-key guessing, implicit host-home scanning and iteration-substring exhaustion are not preserved behaviors.
