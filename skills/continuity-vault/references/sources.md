# Sources and adaptation

This skill is independently authored from required functions. Earlier plugin editions and public-framework methods informed the local implementation. Source study is not proof of current host behavior, and source repositories are not runtime prerequisites.

## Original capability sources

- Codex Continuity Vault: six methods including Session Compounder, five Frontier Extraction techniques, durable handoff, promotion, trust audit and graph work.
- Claude Continuity Vault: five methods with different graph and host guidance. The preserved method union includes Session Compounder rather than adopting the smaller catalog.

The new methods separate extraction from instruction changes, graphs from their provider, and structured validation from evidence or permission. A valid blocked record and a clean empty audit are supported outcomes. Old directory shape, repeated generic schemas, automatic companion probing, model pins and permissive promotion assumptions are not preserved as requirements.

## Pstack and Ponytail

[Pstack](https://github.com/cursor/plugins/tree/9f451cf875ad1239912762f67741e8e5ba6ac0f1/pstack), version 0.15.15, informs scoped reconstruction, current mechanics versus historical intent, failed/reverted attempts, evidence conditions, source-aware reflection, corrected decision history, honest coverage and selective revalidation. It does not authorize hidden transcript reads, automatic WIP commits, broad investigator fleets, backlog writes, a scheduler or a persistent controller.

Ponytail's supplied development principles guide this build: need first, reuse adequate code, prefer native capability then standard library then an installed dependency, choose a direct operation and stop at the smallest correct readable safe testable implementation. It is not a runtime dependency. The runtime remains model-neutral and independent of personal siblings.

## Reused local support

`scripts/evidence.py` reuses the Coding Studio selected-file evidence helper. Its complete implementation ships locally; it does not import Coding Studio. The guide is adapted for this skill's name. Reuse avoids another competing selected-file hashing implementation and does not establish native execution or acceptance.

`scripts/record_check.py` is new local code for the narrow session/audit consistency failures. Neither script grants authority, certifies source truth or proves native delivery. Ordinary methods work without either script when their exact checks are unnecessary.
