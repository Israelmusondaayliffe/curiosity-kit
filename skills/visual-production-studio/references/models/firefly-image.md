Evidence checked 9 October 2026. Guide-backed image craft; product controls are not partner-model or native API contracts. Firefly Image 5, Image 4 and Image 4 Ultra remain distinct selections. No generation or account availability was tested.

## Construct the prompt
Describe the visible subject and action first, then composition, lighting and material/style. Put the intended use into concrete visual requirements: a packaging hero may need a clear label and empty copy area, not the vague word “commercial.” For a supplied style reference, state which treatment to borrow; for composition reference, state the framing or spatial arrangement. Neither automatically authorizes borrowing a person's identity.

For an edit, name the local change and the important retained content. Avoid writing a new scene description that contradicts the selected source. Keep product UI choices, reference strength and model selection outside the prose unless the exact selected surface requires otherwise.

## Authored example, not an output test
Image 5 creation: “An amber glass soap bottle stands on pale limestone, photographed straight-on at label height. The bottle occupies the left third; the right half is a clean warm-grey wall for headline placement. Broad window light from the left, soft contact shadow, legible front label reading ‘FIELD’.”

Edit: “Replace the limestone base with dark walnut. Keep the bottle, label lettering, camera position and wall unchanged.” Use the actual previous result as edit source.
