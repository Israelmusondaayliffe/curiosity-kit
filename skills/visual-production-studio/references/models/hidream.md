## Task-aware prompting
Choose creation, one-reference editing or multiple-reference work before setting up the runtime. Multiple references can supply subject, layout or skeleton roles; explicitly label what is borrowed from each. Use edit instructions for local change instead of recreating the full source. The optional prompt agent/refiner is a separate local/API component, not mandatory user syntax or permission to send assets externally.

Authored multi-reference brief: “Use the person from the subject reference and the seated arrangement from the layout reference. Keep the person's clothing and face; borrow only the layout's camera angle and placement.” This specifies intent. Actual reference inputs and settings must come from the chosen variant's usage example; do not reuse one guidance scale across Full and Dev variants.
