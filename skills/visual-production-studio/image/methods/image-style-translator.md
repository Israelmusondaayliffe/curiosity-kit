# Change an image's medium or style

Determine whether the brief asks for a faithful transformation or a creative reinterpretation. A new medium can keep pose and composition fixed; a restaged shot should change them only when the request allows it.

1. Inspect the source's identity, shapes, proportions, palette, light, depth and mood. Assign separate roles to content and style references. A target style source outranks a generic named-style recipe for its assigned treatment.
2. Describe the target through its visible mechanics. Print uses screens, ink and registration; painting uses pigment, stroke, surface and layering; drawing uses line and value; sculpture uses mass and construction; textiles use fiber, stitch or weave; 3D uses geometry, finish, light and rendering treatment.
3. Translate space and edges. Decide whether depth flattens, shadows become blocks, contours become broken lines, grain replaces smooth gradients or highlights become stylized marks. Use camera-era vocabulary only when photographic or cinematic imitation is intended.
4. Keep recognition anchors and the allowed composition. In reinterpretation, state which pose, setting or framing choices may develop. Do not make a historical anti-paste recipe's pose change compulsory.
5. Write the requested prompt or alternatives. Vary meaningful treatment choices while holding protected content. A ten-style sampler is an available task, not a default quota.

Check that the prompt actually describes the medium instead of only naming it, and that treatment changes do not accidentally normalize anatomy or impose photographic skin on a drawing. Review actual output only when provided.
