# Arrange elements in an image

Use this method when placement is the main design problem. Make the spatial relationships explicit enough to follow without promising pixel-level placement from prose.

1. Inventory the required objects, panels, labels and exact copy. Mark fixed positions, repetitions and areas open to exploration. A supplied layout reference controls its assigned geometry.
2. Set canvas orientation and major divisions. Establish the dominant element, relative scale, negative space and reading path. Use foreground, middle distance and background for a scene; margins, columns and alignment for a designed page.
3. Specify relationships: left/right, above/below, inside/outside, adjacency, overlap, occlusion and contact. Anchor directions to the viewer or an identified subject so they cannot flip accidentally. Explain what may extend beyond the crop.
4. Balance the arrangement. Check whether large elements obscure required details, whether hierarchy survives at the intended size and whether spacing supports the visual job. Keep intentional asymmetry or repetition.
5. Write a complete prompt. Coordinates and percentages describe intent unless the selected tool exposes real placement controls. For alternatives, hold required content and vary only the unlocked arrangement.

Check required element counts, scale, reading direction and exact text. A composite layout remains one image; it does not satisfy a request for separate files. A factual diagram also needs verified relationships and data.

[Layout methods](../references/image-layout-architect/layout-methods.md) and [preserved inventory/position templates](../references/image-layout-architect/source-layout-templates.md) provide full forms. No fixed ten-layout quota is required. On a render, report actual placement differences with specific regions rather than claiming perfect geometry from the draft.
