# Compose an editorial image or page

Establish what the page must communicate, to whom and at what format. A poster, cover, spread and campaign key visual need different hierarchies even when they share the same photograph.

1. Gather approved copy, supplied images, palette, page shape and intended design tradition. Define what should be read first and what the reader should discover next.
2. Compose the image and type together. Set focal point, headline scale, supporting copy, margins, alignment, negative space and the graphic device that makes the page recognizable. Avoid describing an unrelated image and adding text as an afterthought.
3. Translate references into visible design choices. Identify their conceptual tension, color/material relationships, typography, grid, rhythm and application logic. No preliminary identity board is required.
4. Make the medium and treatment tangible: halftone or clean raster, rough registration or exact geometry, paper grain, ink density, image crop and type/image overlap. A tradition name alone is not sufficient art direction.
5. Distinguish a single page, one spread and multiple separate pages. If the requested object is an image of a UI or slide, keep its page-level hierarchy and exact text, while stating that the output is a visual image rather than a functional interface or editable deck.

Return a complete page prompt in the requested form. Check copy, reading order, frame and output kind; only a rendered image can establish actual legibility.
