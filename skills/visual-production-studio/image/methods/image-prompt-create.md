# Create an image prompt

Turn the brief into an image the reader can picture. A useful prompt states a visible moment, not a list of compliments about quality.

## Work from the brief

1. Identify the subject, its action or state, the setting, medium and intended use. Keep intentional absurdity, impossible scale or fictional anatomy. Resolve a missing detail yourself when it is an open creative choice; ask only if it changes the requested subject or result.
2. Choose the picture's organizing idea. Place the main subject, set its scale against the frame, describe foreground and background when they matter, and choose what should remain empty. A simple icon needs fewer scene instructions than a crowded historical illustration.
3. Write the medium through visible behavior. In a photograph, describe light direction, softness, reflected surroundings, depth of field and a lens only if these affect the image. In a drawing, use line, shape, fill, mark density and paper. In sculpture or 3D, describe construction, weight, joints, finish and contact.
4. Make materials specific. Glass transmits and reflects; cloth folds under tension; metal reflects its surroundings; worn surfaces reveal where they have been handled. Match detail to viewing distance. A full-body portrait does not need a pore inventory.
5. Add exact visible copy, background or cutout treatment and the requested frame. A white backdrop does not establish an alpha channel. If transparent output is requested, retain that file requirement for actual delivery checks.
6. Return the complete prompt. For alternatives, vary the unlocked idea rather than adding synonyms. In open exploration, explore different concepts; in directed work, vary only the named axis; in partly directed work, keep the given center and explore nearby choices.

Check that the image has a clear focal point, the material and lighting agree, and every creative addition earns space. A coherent shoot may keep one aesthetic while changing its moments.
