## Resolve the meaningful differences

- A poster/cover/spread uses editorial. Lettering as the subject uses typography. Factual relationships use infographic. Placement as the main problem uses layout. Research supplies facts where needed without becoming a compulsory workflow.
- Series develops continuity. Storyboard develops ordered beats. Multi-output writes one submission for separate files. Campaign-grid writes one composite with cells. A shot list is independently complete before prompting.
- Faithful illustration/photo conversion preserves the reference through a specific medium change. Style translation also supports broader reinterpretation. Camera directions can be controlled studies or continuing shots, according to the brief.
- A brand name in an ordinary image does not require brand interpretation or Brand Studio. Use brand interpretation when transferring visual identity is the creative task.
- Midjourney creation, editing and browser operations retain separate methods. A historical creation profile cannot forbid the separate edit or Draft route.
- A named family/version selects only its relevant model reference. No named model needs a generic provider substitute. Model-neutral craft does not require the model index.
