# Saved production route identifiers

The source route identifiers remain stable; each resolves to a complete local method. Record only the owners needed for this brief. This is a selective planning aid, not an instruction to load every route.

- faceless-explainer: narrated topic/article video without an on-camera host. [Owner](../../faceless-explainer/METHOD.md).
- product-launch: product announcement, feature reveal or commercial launch story. [Owner](../../product-launch-video/METHOD.md).
- pr-story: verified code change or pull request explanation. [Owner](../../pr-to-video/METHOD.md).
- website-capture: capture and present an actual website or web product. [Owner](../../website-to-video/METHOD.md).
- music-visualization: visuals synchronized to supplied music. [Owner](../../music-to-video/METHOD.md).
- slideshow: still-image/presentation-led work with the requested interactive/video delivery. [Owner](../../slideshow/METHOD.md).
- motion-graphics: type, diagrams, charts, maps or designed animation. [Owner](../../motion-graphics/METHOD.md).
- general-video: mixed authored production not owned by a specialist. [Owner](../../general-video/METHOD.md).
- previs and previs-to-sequence: two preserved source aliases for storyboard prompts from brief/image, video prompting from an inspected board, a complete chain or reconstruction. [Owner](../../../video/methods/previs.md). Runtime is prompt-only or external.

Supporting owner IDs and methods:

- embedded-captions: [burned-in captions](../../embedded-captions/METHOD.md)
- graphic-overlays: [lower thirds, callouts, frames and labels](../../graphic-overlays/METHOD.md)
- media-use: [source media inspection/acquisition](../../media-use/METHOD.md)
- video-prompt-builder: legacy owner ID for [new model-ready prompts](../../../video/methods/build.md) or the selected animate/deconstruct/remix/Seedance method
- remotion-to-hyperframes: [explicit project migration](../../remotion-to-hyperframes/METHOD.md)
- video-delivery-qc: [actual rendered output checks](../../video-delivery-qc/METHOD.md)

The saved field is named skills for source compatibility; these values identify methods within this one studio, not separately installed dependencies. The validator checks nonempty owner labels, not semantic correctness of the sequence. Exact model choice, permissions, available engine and delivery proof require the complete owning method.
