# Add scene-aware captions

Use for adding readable subtitles, embedded cinematic typography, or a named VFX caption identity to an existing speech-bearing clip. The output is a caption plan, preview, or rendered composite according to the request. A prompt-only request stops at the plan. Keep the supplied footage and voice authoritative; do not generate replacement speech or rebuild the video.

## Choose the useful path

1. Confirm the source clip, intended audience/platform, reading priority, output format and any named identity. Reuse answers already given. Preserve an explicitly selected identity. If identity is undecided, probe the clip, shortlist two or three scene-appropriate identities from `identity-registry.json`, recommend one and let the user choose, unless they delegated that preference.
2. Load this method once, then the selected `dna/<identity>.json` or `themes/<identity>.json`. Do not read every theme, the complete compiler, old entrypoints or the entire catalog as a prerequisite. The original `CATALOG.md` remains an optional richer comparison reference.
3. Use the live cinematic engine for the ten column-flow DNAs; use the theme engine for the 26 themed constitutions. `anchor` is the quiet verbatim rail with optional embedded peak. Standard is retired, with its role served by anchor. Do not silently revive an unavailable Standard compiler.
4. Read `references/rail.md` when using a rail; read `references/composition-craft.md` for embedding; read `references/reference-bar.md` for visual acceptance. Pull typography, motion, scene/layout or failure references only for the decision at hand. Historical examples under `modes/cinematic/_archive/`, cinematic-cream and `references/example-renders/` are design references, not current tested render routes.

The ten cinematic identities are cream, ink, editorial, keynote, documentary, loud, neon, glitch, chrome and velocity. The themes are anchor, arcade, aurora, biolume, brush, chalkboard, dossier, graffiti, hologram, inkwater, laser, lastpage, neonsign, nightcity, ordnance, papercut, popup, ransom, scoreboard, spectrum, stardust, stomp, terminal, thunder, transit and vhs. All 23 theme body paradigms and 24 hero setpieces remain in the local compiler. These counts describe preserved identities, not 36 qualified render passes. Respect each DNA's delivery qualification, including `rail: unvalidated`.

## Admit the shot before authoring

Probe duration, audio streams, dimensions, sample aspect ratio, rotation and rational frame rate with installed ffprobe. View frames at 20%, 50% and 80%, plus a 1 fps contact sheet for baked captions or hard cuts. A suitable default is a steady single visible human subject, intelligible speech, at least three seconds and usable text space. Reject or propose an appropriate alternative for silence, untrustworthy transcription, multiple speakers/cuts, heavy existing typography or unstable handheld matting. For multiple shots, propose splitting and independently qualifying each shot; do not force one matte across cuts. Do not cover or inpaint baked captions without a separate edit request.

Inspect letterbox/pillarbox bounds. Keep captions inside the actual content rectangle. Probe candidate regions: luminance below about 60 supports light type; 60–180 needs a scrim; above 180 needs opaque type/scrim or an identity designed for bright footage. Ink's dark multiply treatment is the bright-scene choice; cream's screen treatment is not permission to recolor its identity. Choose by tone × shot × platform: documentary/conversational/energetic/poetic/keynote/investigative/music-video; close/mid/wide shot; portrait/landscape/square/broadcast. Check register and content fit before using a spectacle-heavy theme.

For default readable captions, preserve every spoken word. Editorial or lyrical highlights may intentionally omit words only when the user asks for or approves that coverage. Label the mode and retain the complete source transcript separately. Old advice recommending partial lyrical coverage does not authorize abridging accessibility captions. Filler/stutter edits must be deliberate, not hidden matcher skips.

## Prepare one source and one timebase

Work in a dedicated project directory; preserve the original source outside it. Explicitly copy or symlink the approved clip to `source.mp4` before parallel preparation. Never select the first/largest video or reuse a generated `final.mp4` as input. Record source path, SHA-256, probe result, runtime/tool versions, language/alignment model and selected identity. Cache receipts bind the source bytes and relevant model/options. Replaced source, partial extraction, missing receipt or changed options requires a fresh isolated project or deliberate archival of old generated artifacts; file counts and equal duration alone do not prove identity.

Read `DEPENDENCIES.md` before executing. The helpers do not provision missing software, credentials or models. Use existing approved Node/Python/ffmpeg, a compatible built HyperFrames checkout, Puppeteer/Chromium, sharp, pinned local GSAP, speech/alignment models and human segmentation weights. First-run model downloads and package installation are setup actions, not implicit caption preparation. Use an isolated HOME/cache during tests. Never broaden browser security flags or kill unrelated browser processes.

Run `bash scripts/prepare.sh PROJECT` only after the source and dependencies are ready. It parallelizes matte, word transcription and audio envelope, then computes safe zones. The intended outputs are `frames_bg/`, `frames_fg/`, `matte.fps`, `transcript.json`, `envelope.json` and `safe-zones.json`. Envelope absence is an explicit neutral-amplitude fallback, not measured audio reactivity. Validate existence, source identity and counts before advancing.

Matte extraction preserves a finite decimal/rational rate (29.97 is not 2997). Record any VFR-to-CFR normalization and use the same timestamps for video, alpha, measurement and render. Frame lookup is zero-based time converted to one-based filenames. Unequal frame counts are blocked for reconciliation; do not stretch/pad masks until counts merely look equal. Use CPU inference where qualified. Historical CoreML artifacts are not permission to select CoreML for the human-matting route.

Prefer an already installed WhisperX forced-alignment route, with an installed HyperFrames Whisper fallback only when authorized and available. Record actual model/engine and detected language; unknown language is `und`, never invented English. Reject null-status, signalled, timed-out or stale subprocess output. Nonempty text must have finite nonnegative, ordered, positive-duration word timestamps within media bounds. Untimed tokens need alignment review, not fabricated interpolation. Review no-speech/silence and terminal-tail warnings against the audio; a language-looking hallucination over silence is not a transcript. If a heavier model is appropriate, preserve the language and approved local/provider boundary.

View at least two or three foreground masks against original frames. Human segmentation can include nearby furniture and lose held objects. Safe zones measure alpha and luminance, not semantic props. Inspect every selected band for microphones, screens, signage, lights and product edges. A clean score cannot replace looking at the shot.

## Author the selected engine

### Cinematic block workflow

The selected DNA locks type, palette, blend, optical response and motion. Scene palette, light direction, blur/depth and RMS should parameterize that identity, not erase it. Documentary deliberately has no hero; loud deliberately puts body announcements in front. Editorial italics and other newer DNA treatments remain available despite older blanket prohibitions.

Read `safe-zones.json`. Anchor narration in hugLeft/hugRight strips near the silhouette when readable; far corners are fallback. Use sentence-window zones to account for movement, consistent planes and content bounds. A narration `fg` recommendation need not force the hero forward. Prefer the measured hero band on the subject when feasible; foreground hero is a last resort or explicit design choice. Preserve a source-bound explanation for overrides.

Write `cinematic.json`: dna, width, height, fps and thought blocks; each block names a plane and contains lines of source words, optional font-size/weight/style CSS, optional `hero: true`, display text and explicit layer. Group roughly 2–5 words at clause boundaries, preserving spoken order. Use at most one hero per block, never simultaneous competing heroes, with air between windows; under about 0.6 seconds between peaks deserves review. Distinguish the one largest apex from minor emphasis. A short clip often needs only one or two peaks; do not manufacture a hero for every sentence.

Run `node scripts/make-cinematic.cjs PROJECT`. It matches words sequentially, builds `plan.json`, accumulates within blocks, flips pages between blocks, constructs source-ordered hero lockups and foreground/background depth sandwiches, fits typography, measures and recompiles. Measurement failure or missing fresh samples blocks measured-layout claims. Hero setup → impact → afterglow remains DNA-specific, with quiet and heroless variants intact. Script-like text is literal data, never HTML or executable script.

For designs blocks cannot express, author `plan.json` directly and run `fill-timings.cjs`, `fit-fonts.cjs`, then `make-composition.cjs`. Keep source token/timing distinct from display substitutions. Do not combine multiple spoken words into one timed token. Deliberate display substitutions belong in a task-specific mapping, not an unreviewed edit to global timing exceptions. Give groups valid safe IDs, nonempty words, legal in/out windows and explicit planes. Trusted author CSS is separate from transcript data; do not paste untrusted CSS/IDs into templates.

### Theme constitution workflow

Read only the selected theme JSON and `references/theme-authoring.md`. The identity composes body paradigm × body layer × hero setpiece × foreground effects × plate reaction × linkages. Preserve seeded choreography, fixed-slot layouts, typed/poem/panel/rail/takeover behaviors, glyph writing, linkage timing, adaptive placement and typography. Do not replace a named setpiece with a generic pop animation.

Write `theme.json` with dna, dimensions, duration/timebase and nonempty `lines` in exact transcript order; each is a nonempty array of source words. Add minors for emphasis. `hero` is optional: omission produces a pure-body theme. When present, `hero.match` identifies source words and `hero.text` controls display. Repeated phrases require `hero.wordIndex` (zero-based) or `hero.occurrence` (one-based), never arbitrary first occurrence. Embedded heroes own their words, so omit them from body lines; inline heroes and panel-redact linkage retain them in lines. Full transcript coverage is checked. The current compiler explicitly rejects an all-hero/no-body shape instead of crashing or pretending it is supported.

Run `node scripts/make-theme.cjs PROJECT`; preview before rendering. Output includes index.html, a rail.html when the constitution needs it, a source/output manifest, and `_postfx.sh`. Frame-count effects derive from the actual FPS. Theme-authored plate dim/punch/shake/push/grain is the only default full-frame treatment exception, applied after matte composition so the image moves together. Grain zero must stay zero. Retain source audio when present, and declare a genuinely silent source explicitly.

Nightcity/coverword remains conditional. Supply an appropriately licensed compatible font via `CYBERPUNK_REPLICA_FONT_PATH` plus a project `nightcity-font-rights.json` recording its hash, license, intended use and embedding permission. The restricted fan-kit TTF is not shipped. Existence of a font path is not rights clearance or proof its metrics match. Preserve the font notices and Hershey acknowledgement when distributing editable font/path material. Missing glyphs, CJK/RTL shaping and arbitrary scripts need font-specific inspection; Unicode matching does not establish glyph support. Never render unknown draw-on glyphs as blanks.

## Preview, review, render

Run `node scripts/preview-frames.cjs PROJECT [TIMES...]` for faithful source + captions + matte + rail composites. Review entrance, settled hold, handoff and exit of each group/peak, plus edge cases caused by moving subject/props. Check washout, text-on-text, reading order, hero presence, balance, readable glyph bounds, fixed slots and cropping. Hero occlusion around 30–55% is an artistic target; readable body word occlusion is a different metric. Geometric rectangle overlap is not pixel-perfect glyph visibility. SVG-painted setpieces require separate visual/SVG review.

Use the positive checks in `references/reference-bar.md`: poster test, timid test, one-glance hierarchy, scene handshake and dead-air audit. Check face visibility over time (the source goal is at least 30% uncovered within each 0.3-second window), role-appropriate reading holds, transcript/audio alignment, contrast at actual visible opacity, matte edges, adjacent group interactions and final display scale. Body reading generally needs at least about 0.5 seconds; deliberate brief decorative impacts do not excuse unreadable words. Old 0.4/1-second guidance remains role-specific, not one contradictory universal threshold. Intentional decorative bleed requires a documented exception; readable glyphs must remain legible.

For a fresh-eyes review, provide the actual contact sheet and selected route's criteria, without telling the reviewer the desired verdict. Apply fixes to authoring files, recompile and generate fresh previews. Do not carry forward stale measurements or old PASS notes.

For an authorized rendered output, run `bash scripts/render-and-composite.sh PROJECT`. It requires the current output manifest and pinned local `_caption_gsap.js`; orphan foreground/rail layers block rendering. Preserve independent background, foreground and rail channels, correct alpha, selected blend mode and source audio. For theme output, run the generated post-effect step only after a successfully probed composite (or use `render-theme.sh` after the preview review); final_fx.mp4 is the post-plate result. Retain pre-effect final.mp4 for comparison.

Gates report PASS, FAIL, BLOCKED, UNKNOWN, UNRUN or explicitly NOT_APPLICABLE/OVERRIDDEN. Missing browser/timeline/masks/expected captions, zero samples, timeout or stale output cannot become PASS. A documented skip/override stays visible. Snapshot review alone does not establish motion/audio quality. Inspect actual fresh final frames, duration, dimensions, frame rate, streams, motion and audio before claiming delivery QC. Supply the requested artifact and a concise evidence summary with remaining qualifications; native render, glyph and aesthetic status remain unverified until actually checked.
