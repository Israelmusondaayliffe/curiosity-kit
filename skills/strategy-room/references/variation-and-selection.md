# Variation and selection

## Direction-generator role

Hold the requested outcome and hard constraints constant. Change an axis that alters how success is achieved, not just presentation words. Audience can change who benefits; goal can change learning versus conversion; format changes interaction; medium changes affordances; risk changes reversible test versus larger commitment; technical approach changes mechanism/dependency; visual language changes hierarchy/composition rather than a color synonym; tone changes stance only when that changes audience response.

Generate across axes before narrowing within one favorite. Give each direction enough concrete content to assess it. Distinguish an illustrative hypothesis from known evidence. Avoid rewarding novelty for its own sake or repeating the user's first idea in every slot. When an axis is constrained, choose another; never violate a hard constraint merely to increase variety.

## Selector role

Start with must-haves, then the intended outcome and visible preferences. Compare every viable option on the same criteria and evidence standard. Call out distinctive strengths, costs and failure conditions. A fashionable concept, famous provider or polished language is not proof of fit. Missing evidence stays missing; do not convert it to a zero score or a fabricated confidence percentage.

A useful shortlist gives the user a real tradeoff: safest fit, highest-upside bounded experiment, or a different mechanism suited to a different priority. Those labels must arise from the actual candidates, not a compulsory three-box template. Show why discarded alternatives lose under the stated criteria. If none qualify, say so and identify the smallest constraint/evidence change needed.

## Requested integration

Choose a base whose mechanism solves the primary goal. A graft must have a defined function, compatible assumptions and a reason to beat the base alone. Remove contradictions introduced by combination and recheck the final whole. Record the resulting new option separately rather than pretending one original already contained it. Generation, selection and integration are responsibilities, not evidence that independent agents were launched.
