# Sources and limits

This is an independently authored, model-neutral Practice Compiler for a private skill library. Its methods preserve the useful workflows of the two original plugins while replacing their host-specific and unsafe assumptions. Source research does not establish native runtime parity or measured superiority.

## Original requirements

Earlier Practice Compiler editions supplied the original capability baseline.

Preserved functions include explicit cross-source intake, nine signal classes, extraction, read-only preview, repeated evidence, scoped cumulative review, decisions and owner handoffs. Claude's small ownership-question route remains useful. The local methods do not require the former destination siblings to be installed.

The original code had static gaps in adapter dispatch, event-window filtering, cumulative scope, whole-record redaction, identity/lineage and revision-bound approvals. Those are reasons for concrete implementation contracts and regression checks, not claims that a donor was run and failed here. Original tests were read, not executed as part of research.

## Read boundaries

Only selected donor methods informed this adaptation. Broader repositories, integrations and installed caches were not fully audited; no correctness or privacy guarantee is inherited from their names.

No donor hooks/scripts were executed during research. No real user session store, hidden transcript, installed cache or live account was used as test evidence. Qualification is specific to the candidate, environment and recorded cases; source notes do not supply it. A bundled helper's structural result does not prove safe disclosure, authentic consent, causal benefit, successful installation or all-host behavior.
