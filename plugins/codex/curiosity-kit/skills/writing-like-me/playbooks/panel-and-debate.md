# Expanded panel and debate

Both require affirmative selection. They are distinct from the default two-reviewer delivery check. A mention, quotation or generic “improve this” does not activate them. Read the actual draft and relevant context; no status file is required. Establish audience, genre, stage and goal from supplied material and state only assumptions that affect review.

Use the user-selected roster. Otherwise propose the smallest useful set of complementary lenses and finite launch/round cap, then obtain confirmation. Do not enforce historical four-to-six-person quotas. Read each selected [local lens](../lenses/index.md); no installed sibling reviewer is required.

## Select for purpose

Reader gives first-contact orientation; Mom probes non-expert access; hostile read tests defensibility; Hemingway examines economy; Sedaris explores supported humor/specificity; Sorkin examines movement; Vonnegut tests story fundamentals; Hitchcock examines suspense. Useful tensions include economy versus specificity, orientation versus mystery, context versus brevity, accessibility versus economy, momentum versus observation and rigor versus voice. Choose for the actual material, not a default roster by genre.

## Panel: one independent round

Give each permitted independent worker the same frozen draft, relevant brief/sources/guides and only its selected lens. Neither reads another report first, edits the shared draft, saves lessons or starts children. Use the host's actual independent mechanism and selected/configured suitable model; never invent an agent type or model. Missing/failed workers remain unavailable.

Synthesize the actual reports: shared findings, productive tensions, unique insights and priorities tied to this piece. Quote the contested passage, explain what competing recommendations protect, and keep consequential artistic choices with the writer. Agreement is not evidence by itself. If independence cannot run, offer an explicitly labeled single-writer multi-lens assessment when useful; never present it as a panel of independent reviewers.

## Debate: bounded deliberation

Start with the same independent positions. Identify a small number of meaningful tensions. Send each involved reviewer the exact passage, both positions and a concrete challenge. Responses are concede, hold or propose, with source/text-grounded reasons. No response is unavailable, not a hold or vote.

Record each tension as resolved, stalemate or proposal for writer judgment. A compromise must preserve what both sides identify as important, not average the prose into blandness. If no material tension exists, skip challenge rounds. Stop when positions repeat, the question is resolved or the agreed cap is reached; do not automatically run four rounds or spend extra budget.

Return resolved tensions and reasons, unresolved positions and stakes, proposed compromises with tradeoffs, shared findings and any consequential remaining writer choice. A request for diagnosis does not authorize rewriting. Integrate only an authorized revision, then use the ordinary bounded finish path. Do not automatically escalate a panel to debate or rerun the whole roster after a small repair.
