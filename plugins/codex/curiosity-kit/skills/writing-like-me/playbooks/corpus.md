# Emergent cross-piece comparison

Explicit selection only. Use for a named set of drafts or sources and an actual comparison question: voice drift, opening patterns, repeated objections/transitions, unsupported claims or notes-to-outline coverage. A generic writing request does not authorize corpus exploration.

Resolve the exact selected set. Read only it and relevant task context; do not search unrelated personal files or infer missing pieces were read. Distinguish authored samples, quoted sources, accepted writing and rejected model drafts. Track which version of each piece is being compared.

Choose the relevant local craft: voice-check for sentence behavior, craft/BLUF for openings, objections for arguments, claims for support, outline for coverage. Compare concrete passages and their functions. A repeated technical term may reflect subject matter, not a portable preference. One selected passage may be a local choice, not a durable voice rule.

Return the useful pattern with examples, counterexamples and limits. State which source notes reached the outline and which did not, rather than inventing a coverage score. A sparse set can support a narrow observation but not a writer-wide conclusion.

Do not rewrite the corpus or save findings into guides without the requested operation and confirmation. [Guides](guides.md) handles any confirmed lesson. Broader workflow proposals remain proposals. Stop when the requested comparison is answered; do not reopen the general writing lifecycle.
