# Curiosity Compass

Use when explicitly selected or routed by Strategy Room to prioritize rough ideas/questions/opportunities competing for attention. It returns zero to three worthwhile directions and bounded tests. It does not synthesize a mature decision record, select who does the work, or execute a project. Read the [common evidence/choice contract](../references/evidence-and-choice.md); use the [focus template](../assets/curiosity-compass.md) as an output coverage check.

## Frame the attention decision

State the beneficiary, available attention/resources, constraints, horizon and consequence of choosing poorly. Normalize the supplied ideas into distinct candidate directions. Merge true duplicates but retain differences that alter user, mechanism, outcome or test. Do not discard learning/creative value merely because the idea is not monetized.

Choose a small set of decision-relevant criteria, usually four to six: expected value, urgency, evidence, fit, effort, reversibility, learning value or downside. Show relative importance. Infer priorities only from clear user statements; ask when a missing preference could change which ideas clear the floor. Define hard must-haves separately so a weighted average cannot rescue a disqualifier.

## Compare without fake precision

Inspect supplied sources first; verify current facts only if they materially change the comparison and the research is within scope. Use one intelligible scale for all candidates, with short reasons for material differences. Unknown is not zero. Prefer qualitative or bounded scores where evidence is thin; if using numbers, define their anchors and do not present invented probabilities.

Apply a visible viability floor based on must-haves and minimum useful value. Check whether plausible changes in uncertain evidence or priorities reverse the ranking. If so, identify that sensitivity and the cheap observation/choice that resolves it. Novelty, excitement and prior attachment earn weight only when they meet an explicit criterion.

## Return zero to three

Recommend zero, one, two or three qualifying directions. No qualifying idea is a legitimate outcome, not a failure to brainstorm. For each, state why it matters, why now, what could make it wrong, the evidence that would change the ranking and the cheapest useful first test with an observable result. Do not force three or fill the shortlist with below-floor ideas.

Return frame, criteria/weights, candidate comparison, uncertainty, viability floor and ranked focus/tests. Check common criteria, hard constraints, no unsupported winner, and whether the test could actually change a decision. Stop at attention and test recommendations; do not start research campaigns, purchases, publication or assignments.
