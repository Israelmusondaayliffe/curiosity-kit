## Useful compositions and near misses

A recent-evidence question can fit Last30Days; a substantial mixed-source report can fit Knowledge Work; a selected-run cost/acceptance comparison belongs to Observatory. Founder interprets commercial relevance, Strategy settles a consequential choice, and Data Storytelling communicates checked results. Use only the owners needed for the requested output.

Web owns a web product and browser acceptance. Coding owns software behavior. HE owns assistant configuration and reusable skills, even when code is part of the skill. Model Prompt Lab owns task prompts. Chief capability governance can inspect and prepare a handoff without pretending to perform HE's full build.

Choose one actual run controller. Outcome fits accepted-goal delivery; LoopKit fits iterative feedback; protected graph/critic/proof engines require their own selection and contract. Chief of Staff integrates the result while that owner retains state, attempts and stop conditions.

Writing, Guides and Explanation each have complete local craft. An ordinary paragraph does not need all three. Visual can supply a Web asset with agreed dimensions, rights and source identity. AI Film is a separately selected film method. Brand is deferred, not silently absorbed here.

Memory, Continuity, Practice and ProofLoop lessons serve different purposes. A saved handoff is not installed memory; a diagnosed pattern is not an approved lasting rule. Do not create a parallel ambient learning store.
