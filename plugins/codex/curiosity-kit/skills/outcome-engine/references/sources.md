# Sources and adaptation limits

This independently authored skill preserves Outcome Engine's useful methods while removing compulsory personal-skill handoffs and donor host setup. These links are provenance, not resources the runtime must fetch. Task facts come from the user's actual authorized sources.

## Originals

Earlier Outcome Engine editions supplied the original capability baseline.

Local methods preserve briefing, action slices, evidence-led delivery, system review, intake/resume and bounded clarification. Codex supplies the fuller bounded-test ledger, multi-asset control and workflow pilot. Claude supplies the local decision interview. Their four/two structural validators informed the new read-only checker, which is written independently and has a different documented interface. Original historical benchmark/usage claims are not evidence for this candidate.

Original notices attribute precursor methods to Matt Pocock's collection and article “5 Agent Skills I Use Every Day,” and the Codex notice also credits Signal to System's experiment-designer-and-ledger, workflow-clinic and creative-project-control-room. Those notices were read; they do not mean this build audited or executed those separate plugin trees. Their useful functions present inside Outcome Engine are retained locally.

Original contributions are licensed under the package-root MIT LICENSE; third-party material retains its stated terms. No credentials, account state, participant records or machine-local files belong in this skill.

## Relevant public methods

- [Pstack](https://github.com/cursor/plugins/tree/ccb5507cec1546dc88135c1139c811e6c59115ba/pstack): real observable verification, riskiest-unknown-first work, small verifiable units, reversible migration boundaries, independent measurements and honest inconclusive results. No fixed worker/model count, scheduled audit loop, PR policy, bootstrap or compulsory sibling chain is imported.
- Lauren Tan's official Potato articles, [Part 1](https://x.com/poteto/article/2094457600259842065), August 31, 2026, and [Part 2](https://x.com/poteto/article/2097732320606507506), September 9, 2026: reproducible verification and working backward from the intended experience through context and prototypes. These ideas are attributed through prior research; this copy claims no new article-body reading or execution. Immutable source/claim records are not attributed as a named article mechanism.
- [Matt Pocock](https://github.com/mattpocock/skills/tree/f3fc5632f401156837ee3872f14fe33ccf1024ea): synthesize settled context, complete vertical slices, dependency-frontier execution, wide-change expand/migrate/contract, independent acceptance oracles, and useful responsibility boundaries. Tracker setup/publication, automatic branch/reset/cleanup, required broad interviews and mandatory CDN reports are omitted.
- [Superpowers](https://github.com/obra/superpowers/tree/8ca22dba9a94f28898bbce59f2537ff4d87c747d): consumed/produced contract preflight, useful task sizing, exact-version proof, local resume and evidence-based review. No external hooks/scripts were executed. Its source methods are a benchmark, not runtime qualification or permission to run its code. Essential unresolved findings cannot be parked as completed work.
- [Gstack](https://github.com/garrytan/gstack/tree/1d1ce39b4e2beda4626c3f977b368077eb337a73): selected office-hours and plan-review sections contributed approved-versus-proposed values, exact scope assertions, silent-failure/recovery and delivery-path checks. The complete generated framework was not read or imported; no startup scripts, telemetry, mandatory review chain or automatic state changes are used.
- [Ponytail v5](https://github.com/DietrichGebert/ponytail/tree/b088b2df6e08d4306c6a3c3d575fe38c2d2d2989): smallest complete change and concrete correctness/safety/load/test/simplicity review.
