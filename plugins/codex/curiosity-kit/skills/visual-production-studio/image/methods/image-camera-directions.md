# Plan camera directions from an image

Decide from the request whether the camera is the only variable or whether these are new moments in a continuing shoot. A new angle at night already names two changes; it does not require a mode-selection interview.

## Describe a coherent new view

1. Inspect the source and identify the subject's recognition anchors, physical state, world geometry and treatment. Mark unknown back surfaces and off-frame areas as inferred, rather than recovered facts.
2. For a controlled study, hold the subject state, environment, medium and physical light sources. Moving the camera changes apparent highlights, shadow visibility, overlap and perspective even while the lights stay fixed. For a continuing shoot, allow the requested or naturally connected changes in action, gaze and lighting.
3. Choose camera position, height and angle, then distance/crop and lens behavior where useful. State what the new view reveals. “Low rear three-quarter view showing the heel and sole” is more useful than “cinematic angle.”
4. Keep camera movement separate from subject rotation. A product turntable, orbit viewpoint and posed turnaround may reveal the same side through different changes. If several views belong on one sheet, specify each panel and the shared treatment. If separate files are intended, write separate frame directions.
5. Test the view mentally against the scene. Can this camera occupy the proposed place? What occludes what? Does the fixed light still come from the same part of the world? Is a wide-angle distortion intentional?

Return complete still directions with reference, viewpoint, crop, newly visible details and permitted changes. A still can depict an endpoint or implied motion; it cannot contain an actual continuous camera move. Use the requested count, including repeated poses in controlled studies.
