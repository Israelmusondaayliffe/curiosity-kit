# Design one campaign grid

The result is one composite image with several cells. Establish the intended use, rows and columns, reading rhythm and shared visual language before assigning cell contents.

1. Inspect references and separate physical recognition anchors from narrative associations. A product's silhouette, mark or finish may persist while its context changes. A macro or partly occluded appearance can carry identity without repeating the hero view.
2. Give each cell a job. Useful roles include hero still life, material macro, interaction, environment, abstract texture, lived activity, architecture, type-led statement and atmospheric detail. Select roles that fit this campaign; luxury spaces and fashion subjects are optional.
3. Balance scale, density and contrast across the grid. Keep intentional repetition when it creates rhythm. Vary context or camera only where the brief allows; extreme diversity is not an automatic goal.
4. Specify every cell's content and exact text, plus border, gutter, background, alignment and crop rules. State which anchors persist across all cells and which are intentionally absent in a detail or abstract cell.
5. Write a single composite prompt. Check the declared cell inventory against rows and columns. Do not turn these cells into separate requested files without the user's direction.

If a render exists, count the actual cells, read its copy and compare repeated subject details. Distinguish a missing cell from a deliberate span.
