# Build ordered still-image beats

Determine whether the requested artifact is one page of panels, separate still frames or several pages. Keep ordered storytelling distinct from an unordered campaign grid or a continuity series.

1. Establish the story or instructional progression and its essential beats. Separate required actions from optional alternative takes. Give each panel a job such as establishing, acting, reacting, revealing, transitioning or resolving.
2. Write compact character, object and world anchors. Track wardrobe, prop state, geography, screen direction and lighting across the sequence. An insert, landscape or reaction can intentionally omit the protagonist.
3. For every panel, specify the moment, framing, camera position, spatial relationship and emotional change. Show the state before and after an important action so causal continuity can be understood. Dense choreography needs readable beats rather than one vague action pose.
4. Assign exact dialogue to its speaker and specify bubble placement, reading order and any requested sound-effect lettering. Avoid text that contradicts the image. In illustrated instructions, verify physical possibility and step order.
5. For a composite page, define the grid or variable panel layout and enumerate panels in reading order. For separate frames, write complete frame prompts with the shared anchors repeated or an explicit shared-session brief. Page count, panel count and file count are separate.
6. Review transitions, prop continuity, left/right movement, character recognition and the clarity of each beat. Check intentional cuts without forcing every shot into one pose, one camera or a photorealistic treatment.

Deliver still-image prompts or the requested storyboard plan. Video generation is not required. If these stills will later be used as video references, identify their roles without claiming the images have already been uploaded or bound to native first/last-frame controls.

Read [narrative recipes](../references/image-storyboard/gpt-narrative.md), [beat methods](../references/image-storyboard/beat-methods.md) or [Uni boards](../references/image-storyboard/uni-storyboard.md) for the needed full form. Character-bible and video handoff methods can build on this finished still artifact without changing its selected image model.
