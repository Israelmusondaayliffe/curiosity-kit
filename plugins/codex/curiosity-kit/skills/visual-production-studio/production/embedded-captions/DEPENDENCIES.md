# Caption execution dependencies and rights

This owner-local bundle preserves its helper-relative layout. It does not include a built HyperFrames runtime, Puppeteer, sharp, GSAP, browser automation wrapper, speech models or segmentation weights. A usable Node/ffmpeg/Chromium installation alone is insufficient. No installation, package fetch, model download, remote font/script fetch or account setup is authorized by loading this method.

- HyperFrames: an explicitly selected compatible built checkout with packages/cli/dist/cli.js; set HYPERFRAMES_ROOT. The old home-directory discovery fallback is a compatibility lookup, not a qualified/pinned installation. Record actual checkout/version. Verify render flags and alpha support before invoking.
- Node/Bash/Python: existing approved executables. Python draw-on helper uses the standard library. No uvx implicit installation is used by the adapted transcription path.
- Browser/image libraries: Puppeteer plus a compatible Chromium executable and sharp available from the selected HyperFrames node_modules. Removed broad disable-web-security/file-access flags are not to be restored casually. If file-origin restrictions prevent a selected feature, serve the dedicated project from a controlled local origin in a qualified host rather than bypass security.
- GSAP: original templates target 3.14.2; provide that already approved local artifact as project _caption_gsap.js (or CAPTION_GSAP_PATH for theme compilation). Do not fetch a CDN script during a render. Generated HTML without it is authoring output, with browser review UNRUN. No replacement stub is animation parity.
- Media: ffmpeg/ffprobe features required include H.264, MP3 audio extraction, PNG alpha, WebM VP9 alpha or ProRes 4444 as selected. Record versions/codecs and probe real outputs. Preserve source audio mapping; silent-source handling is deliberate.
- Segmentation: u2net_human_seg.onnx is not bundled. Pre-provision an approved model with provenance/hash into the selected isolated HOME cache path. The adapted helper refuses a missing model before the runtime can silently download ~168 MB. Check foreground/source timestamps; model output counts alone are not quality.
- Speech: use installed whisperx and its pinned alignment/model dependencies, or installed selected HyperFrames Whisper. WHISPER_MODELS_READY=1 and WHISPER_MODEL_REVISION document an already verified setup; setting them is not permission to install/download. Keep network unavailable in offline qualification, and record actual detected language and source hash.
- Fonts: 44 local Latin-subset WOFF2 assets and their generated CSS remain; 24 family notices (22 OFL, two Apache) are in licenses/third-party-licenses/fontsource. Latin asset presence does not prove every glyph, arbitrary multilingual shaping or external system fonts. Ship applicable notices with editable font-containing sources.
- Nightcity: CyberpunkReplica.ttf is intentionally external. CYBERPUNK_REPLICA_FONT_PATH must identify a compatible font with valid use/embedding rights; nightcity-font-rights.json must record those rights and hash. Fan-kit terms and derived metrics remain provenance with conditional use. A different font must be remeasured, not silently treated as equivalent.
- Hershey: preserved SVG metadata/acknowledgement in assets/strokefonts and licenses/HERSHEY-NOTICE.txt must accompany distributed font/path source data. The derived path generator now rejects empty or unsupported glyphs instead of producing blanks.

Historical fixtures under the author's Downloads/cap_* workspaces are not bundled. Historical artistic claims and example renders are design evidence, not repeated tests here. Exact native segmentation, full real-GSAP rendering, every artistic branch, glyph accuracy and audio/visual acceptance must be qualified on the actual host. Do not label them PASS from source-preservation or JavaScript syntax checks.
