### Prompt
Describe shot, subject, action, location and aesthetic. Be concrete, iterate simply and avoid overloading subjects. Select intended model explicitly; app default may be Veo3.1 on first use.

### Controls
- Prompt: 1800-word cap in prompting guide
- Camera: Motion-reference upload disables manual shot-size/angle/motion choices
- Fps: App default 24; not universal upstream model limit
- Seed: Exact version-specific field not fully verified
- Duration: Version-specific cap not verified

## Native Firefly video versus hosted partner models

Authored native Firefly video prompt: “Wide shot of a red kite above a grassy hill. The kite dips gently in the breeze while the camera pans right to follow it. Clear afternoon light.” Describe subject, motion, framing and camera explicitly. For I2V, let the actual image establish appearance and focus on movement.

Choose native Firefly or the exact named partner before setting controls. Shared web UI widgets, a first-use default and Firefly Video2 Preview marketing do not establish identical upstream schemas. Sound generation, partner audio and image-to-video boundaries remain operation-specific. Current Video2 native API craft/schema qualification is incomplete.
