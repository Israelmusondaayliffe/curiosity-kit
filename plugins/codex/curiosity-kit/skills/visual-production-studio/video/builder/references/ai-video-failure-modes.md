# AI Video Failure Modes

Apply risks by model and mode. Do not turn a limitation from one model generation into a blanket rule for another.

## Cross-model risks

- Conflicting identity references can blend faces, wardrobe, and body features. Assign one controlling reference per property and state what must not transfer.
- Several simultaneous independent actions can create merged bodies, duplicated props, or unclear causality. Give each beat one primary change.
- Complex hands, object grips, liquid collisions, mirrors, and fine distant detail remain risky. Describe paths, contacts, stationary elements, and camera distance.
- Readable text can fail. State the exact language, exact text, and forbidden languages, then plan postproduction when perfect typography is critical.
- Fast camera moves can warp geometry. State start, path, speed, end position, and the subject relationship.
- Contradictory style, lighting, or camera clauses cause unstable results. Resolve conflicts before adding more detail.

## Seedance 2.5 mode risks

- A 30-second prompt without timed beats can bunch action at the beginning or rush the ending. Use time budgets and end states.
- A continuous one-take without a physical route can teleport the camera or subject. Describe doors, occlusions, handoffs, and operator position.
- An extension that restates old action can regenerate or contradict the source. Describe only the new segment and protect prior frames.
- A local edit without a preservation list can spread into identity, motion, lighting, or audio. Use target, change, timing, and unchanged elements.
- Many references without positive and negative roles can leak. Treat platform capacity and reliable working set as different questions.
- Ultra-long beta can drift in identity, palette, prop ownership, camera language, and audio. Repeat global anchors at both ends and rebind references near use.
- Beat-cut music videos fail when one-take prohibitions are inherited. Require hard cuts on beats and reject soft crossfades.
- Frozen-time and rewind sequences can lose object count or paths. Name the frozen set, exempt moving subject, exact reversal path, and landing state.

## Kling and Veo risks

Check the current selected surface before assuming reference tags, duration, audio, editing, or interpolation behavior. Use generic descriptive roles when exact syntax is not verified.

## Risk response

Do not solve every risk with a long negative list.
Choose constraints tied to the actual scene.
If a requested effect remains uncertain, preserve the creative intent and offer a simpler fallback action or a staged generation plan.

## Additional production risks preserved from the other source edition

- Multiple speaking characters: assign dialogue and visible speaking state to the correct subject; inspect lip sync and do not assume either guaranteed failure or guaranteed success.
- Coarse/fine blockouts: distinguish motion/geometry guidance from final rendering; specify limb paths and exclude unwanted placeholder appearance.
- Emotion: express important emotional change through visible posture, gaze and facial performance rather than an abstract label alone.
- Reference density: remove redundant/conflicting inputs while retaining each necessary role; no universal optimal subject count is established here.
- Detailed signage, reflections and distant features: inspect the actual output and plan localized repair or compositing when exact fidelity matters.

The source edition’s claims that a model fixes all crowd, timing, text or negative-prompt problems are historical marketing/community claims, not active guarantees. No blanket two-person, short-shot, mandatory I2V or no-text limit applies.
