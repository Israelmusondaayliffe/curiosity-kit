# Source basis and attribution

Read only for provenance, adaptation or license questions. These references do not add a runtime dependency.

## Original capability baseline

Earlier Operating Graph editions supplied the capability baseline.

The source family supplies the seven workflows, typed graph definitions, original invariant and rewrite mechanisms, standard-library engine, templates and examples. This candidate independently reauthors instructions and repairs the execution contracts while preserving the useful local capabilities. Old plugin packaging, historical progress counts and fabricated launch examples are not runtime proof. Record/receipt changes require the explicit compatibility behavior in the CLI; no existing live run is silently converted.

The original Claude family carries the [MIT notice](licenses/operating-graph-LICENSE.txt). Keep attribution with reused code/resources. Original contributions are licensed under the package-root MIT LICENSE; third-party material retains its stated terms.

## Method references

- [GStack](https://github.com/garrytan/gstack/tree/20eb6202fa8ea83a882e7c0463b722cd8a31af1e): revision-bound review, concrete evidence, bounded repairs and useful disjoint work. [MIT notice](licenses/gstack-LICENSE.txt).
- [PStack](https://github.com/cursor/plugins/tree/ccb5507cec1546dc88135c1139c811e6c59115ba/pstack): self-contained task briefs, dependency context relay, separate writes before serial integration, complete worker accounting. [MIT notice](licenses/pstack-LICENSE.txt).
- [Matt Pocock skills](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336): meaningful blockers, independently verifiable slices, ready frontier and integrated-result review. [MIT notice](licenses/matt-pocock-LICENSE.txt).
- [Ponytail](https://github.com/DietrichGebert/ponytail/tree/9cc65d03aa2da1db7121b912d03596409ee340b8): concrete cause/effect findings and the smallest complete correction. [MIT notice](licenses/ponytail-LICENSE.txt).

Selected files were studied, not entire donor runtimes. Their installers, permissions, fleets, schedules, telemetry and provider choices are not adopted. Notices are retained for method/resource attribution; the graph has no runtime imports from those repositories.

Primary conceptual references include [AWS on idempotent retries](https://aws.amazon.com/builders-library/making-retries-safe-with-idempotent-APIs/), [Temporal event history](https://docs.temporal.io/encyclopedia/event-history) and [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts). They informed bounded intent/reconciliation, replay and interruption questions; this package does not depend on or claim the guarantees of those systems.
