# Review, correct and resume

Inputs: exact current artifact, original brief, source versions/definitions, actual exhibits and prior findings. Review the delivered form, not a remembered draft. Output: distinct judgments on evidence integrity and brief fidelity, actual repairs when authorized, and honest remaining limits.

## Two separate judgments

**Evidence and presentation integrity.** Resolve every load-bearing source pointer and compare the actual supporting material. Reproduce arithmetic only as an identified check. Verify numbers, units, denominators, periods, definitions, precision, intervals and direction. Distinguish source assertions from established findings and recommendations. Challenge a cleaner but unsupported causal explanation. Apply all seven [visual checks](visualize.md#audit-all-seven-dimensions) to material exhibits. Inspect rendered pages/slides/chart pixels and exported files as applicable.

**Brief, reader and decision fidelity.** Does this answer the actual question in the requested form and depth? Are terms grounded for this reader? Is there a usable argument rather than a tool list or source dump? Are recommendations proportionate to the evidence and current authority? Are settled choices preserved and any requested deliverables missing? Does an informative artifact refrain from inventing an action?

Keep both verdicts visible. One cannot offset the other. A polished unsupported conclusion fails integrity. Accurate data that answers a different question fails brief fidelity. Use pass, revise or blocked with concrete location, observation, consequence and smallest repair. Do not write a green verdict beside an unresolved material failure. A genuinely absent issue needs no invented risk or revision entry.

## Real evidence, proportionate review

Use a fresh reader when available and worth the cost for consequential or hard-to-understand work. Give the reader the actual artifact and intended question, not the answer you want them to repeat. Ask what they understand, which source supports the conclusion and which uncertainty changes it. This tests a reader's response within that setting; it is not proof of wider human comprehension. If the author reviews alone, say so when reporting review independence.

For a tiny memo, a direct content/source check may suffice. For a rendered deck, check every final slide. Parsing JSON or counting headings cannot certify truth, readability, complete source coverage or publication readiness. The chart helper's exit0 means the supplied data was rendered consistently with its narrow input contract, not that its caption is true.

## Repair by cause

Identify whether the defect is analytical evidence, semantic claim, visualization, artifact tooling or missing authority. Route an analytical correction to its owner rather than quietly altering values. Correct copy/encoding at the authored source and regenerate affected exports. Keep the old version when recovery matters; use the user-approved destination/version policy and preserve unrelated edits.

When a checked finding changes, find every dependent use: headline, chart values, annotation, table, summary, recommendation, source link and exported copy. Update them together and compare to the revised source. Recheck unaffected evidence only if its dependencies changed. A hand-edited SVG whose data no longer matches its recorded source is not an acceptable shortcut.

Resume from the latest actual artifact and sources, not a stale approval or summary. Verify which version was accepted and which checks applied. If a prior send/upload outcome is uncertain, reconcile it through a supported read before retrying; a local draft cannot prove publication. Do not create a state service or controller just to track ordinary revisions.

## Release and return

Content-ready, visually inspected, native-format complete and sharing-authorized are separate claims. State only those observed. A blocked chart can be omitted only when the user did not require it and its removal leaves a truthful complete result; disclose a material scope change. A no-decision report can be fully ready if it faithfully explains the uncertainty and the next useful evidence.

Deliver the actual artifact with one bounded takeaway, consequential limitations and the precise remaining step. Do not add an unsupported promise of future monitoring or deployment. On an observed recurring failure, record the smallest lesson where authorized: mechanical errors get a focused check when useful; judgment failures get a clearer review criterion. No compulsory retrospective report, new global instructions or automatic workflow installation.
