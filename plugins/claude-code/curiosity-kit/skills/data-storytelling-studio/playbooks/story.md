# Build the full story

Inputs: settled brief, checked findings, source/method notes, and available visual evidence. Output: complete human-facing prose in the requested medium. Do not return an outline when a finished artifact was requested.

## Find the supported message

Write the plain sentence the reader should take away, then test it against the source. Does it name the right population, period, unit and comparator? Does the verb imply causation or certainty that was not established? Is a material counterexample hidden? Use the [evidence contract](../references/evidence.md) for numbers and provenance.

A useful message has an interpretation, not merely a topic. "Service performance" is a topic. "The aggregate rate fell while both recorded case types improved; use case mix before assigning blame" is a bounded interpretation. Do not choose the tidiest message if it requires ignoring contradictory evidence. "The available evidence cannot distinguish these options" can be the central answer.

## Build the reader's path

Use this sequence flexibly:

1. Answer the reader's question in one bounded sentence.
2. Give the minimum context and metric definition needed to understand it.
3. Show the decisive evidence, with the comparison and source close by.
4. Explain the implication and distinguish it from the measured result.
5. Expose the uncertainty or alternative explanation that could change the decision.
6. Recommend an action, conditional decision, or next discriminating evidence only when the purpose calls for it.

Each section earns its place by changing understanding or a decision. Introduce an unfamiliar concept before relying on it. Use the same metric name throughout. A table is good for repeated comparable facts; prose explains reasoning; an exhibit reveals a relationship; a short list names parallel actions. Do not bury a conclusion in the appendix or repeat the same argument as text, chart and decorative callout.

For an executive readout, write the answer, two or three decisive findings if that is what the evidence warrants, the main caveat and the decision/next step. Avoid arbitrary counts when one finding or four necessary conditions are needed. For an informative story, finish with what the result changes in the reader's understanding rather than inventing an owner or deadline.

## Write complete, honest recommendations

Measured finding, interpretation and recommendation are different:

- Finding: what the selected source actually reports.
- Interpretation: why that finding matters for this reader, with the reasoning visible.
- Recommendation: a proposed response and the condition under which it should change.

Use actual costs, estimates, thresholds and owners only when supplied or separately established. A business-impact estimate requires a supported conversion, not multiplying convenient quantities and presenting it as observed revenue. A proposal to test is not evidence that testing happened. Label an unknown owner/date instead of filling a mandatory box with a guess.

For a material choice, explain the relevant alternative or cost of waiting. Do not create three options merely to fill a template. If neither option is supported, say what can be decided now and which missing observation would settle the rest. Keep risks tied to actual consequences, not boilerplate.

## Example of a repair

Draft: "The new policy cut service success by half, so reverse it."

Checked evidence: the reported aggregate rate declined, while each measured case type improved and the case mix changed. Policy assignment was not randomized; costs and unmeasured severity are unavailable.

Repair: "The aggregate declined, but these records do not identify a policy effect. Review case mix and comparable within-type outcomes before deciding whether to reverse the policy." Cite the actual rows and method note. This neither claims the policy worked nor erases the aggregate decline.

## Finish and revise

Draft the whole requested artifact unless the user explicitly chose an interactive workshop. Read it back from the actual saved file. Compare every material headline, number, caption and conclusion with its source. Remove unsupported connective stories and decorative confidence language. A reference that exists but says something else does not support the claim.

Use [review](review.md) before delivery. On revision, retain user edits and accepted evidence. Re-read the latest artifact first; update all dependents of the corrected finding, including chart annotations, opening summary, recommendations and exported versions. Do not silently change the analytical source to make the story consistent.
