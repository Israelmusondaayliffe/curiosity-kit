# Explicit local lenses

An affirmative request selects a lens; quotations, negation, examples and generic improvement do not. Keep the user's operation: diagnose gives findings, propose gives options, revise gives authorized edited text. These are craft perspectives, not claims of an author's participation or a request to imitate a living author's distinctive voice. Do not rewrite a writer into a famous persona.

- [Hostile / cw-asshole](hostile.md): skeptical attack on craft and argument, grounded in actual weaknesses.
- [Hemingway](economy.md): aggressive economy, with meaning and useful voice protected.
- [Hitchcock](suspense.md): stakes, information and earned suspense.
- [Mom](accessibility.md): supportive intelligent non-expert access.
- [Sedaris](humor.md): supported specificity, absurdity and humor opportunities.
- [Sorkin](momentum.md): pacing and forward movement.
- [Vonnegut](story.md): eight story-fundamental questions, adapted to genre.

[First-time reader](reader.md) and [objections](objections.md) are ordinary craft functions, selectable within a writing task or directly, not automatic creative-persona escalations. Reader traces experienced friction; objections tests claims. Neither replaces all developmental editing.

Each method returns to the parent. It does not recursively launch review, save learning, change the writer's thesis or authorize publication. Use exact passages and the actual audience. No forced defect count or score. If no material problem is supported, say so.
