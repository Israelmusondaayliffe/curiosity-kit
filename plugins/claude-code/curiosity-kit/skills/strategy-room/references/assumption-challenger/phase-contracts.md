# Assumption Challenger: phase responsibilities and handoffs

These are execution contracts for the five substantive roles, especially supported opt-in native workers. The complete method is owned by the [Challenger playbook](../../playbooks/assumption-challenger.md); phase-specific expertise lives in the references linked below. Apply [shared evidence and choice definitions](../evidence-and-choice.md). Do not load every resource at intake or run a second duplicate pipeline from this file.

## Execution and continuity

Default serial role-separated work uses the playbook in one context. Opt-in native phase workers use the same method **sequentially**, with actual predecessor artifacts. Neither mode is independent acceptance review. Never launch dependent work before inputs exist or simulate a missing worker/model/tool. Honor user-selected tools/models and obtain an authorized fallback where necessary.

Each handoff carries original input/version; route/effort; actual execution mode; artifact/version references; exclusions; evidence gaps; and the preceding gate outcome. Preserve stable source S IDs, dossier D IDs, input U IDs, hypothesis H IDs and Lx-F finding IDs, or the packet's existing consistent scheme. Revisions preserve identity and original wording. Artifacts may be concise in-context records; saving them is optional and requires an authorized location. Return concise evidence/rationale, not private reasoning transcripts.

Route control stays with the playbook: research-only stops after its dossier; supplied-research does not pretend web research; re-verification preserves old findings while checking changed support. Light narrows coverage, never verification of material final claims. Standard/deep consider all five lenses without mandatory findings. A sound-plan verdict is valid.

## Phase 1: Researcher → research dossier

- **Owns:** evidence gathering and bounded synthesis. Does not critique, decide or certify expertise/ground truth.
- **Receives:** original subject/content, decision/horizon, effort, source mode, authorized source base/tools and material constraints.
- **Method to use:** playbook phase 1 and [research_protocol.md](research_protocol.md), which own decomposition, research mapping, searches, source fit, dates, disagreement and sufficiency.
- **Returns:** populated [research dossier](../../assets/assumption-challenger/research_dossier_template.md): subject, selected/skipped dimensions, traceable findings, source register, disagreement, open questions, sufficiency and limitations; actual structural-check result (required for saved dossiers, optional for unsaved in-context work), or blocked/not run with the reason; structural results remain separate from evidence judgment.
- **Gate:** planner can distinguish supported/contested/unknown claims and trace decisive evidence. A bounded dossier does not prove truth. An incomplete dossier permits only the explicitly supported next scope.
- **Recovery:** reformulate weak searches, inspect original sources or seek contrary evidence when useful. Private/unavailable evidence stays a named gap; request the smallest decisive source or question. Do not pad or invent web reads.

## Phase 2: Planner → analysis plan

- **Owns:** targeted agenda. Does not execute hypotheses or present predicted findings as results.
- **Receives:** original content, dossier/version with assessment and limitations, effort/route and constraints.
- **Method to use:** playbook phase 2 and [analysis_frameworks.md](analysis_frameworks.md); consult [cognitive_biases.md](cognitive_biases.md) for an observed framing issue.
- **Returns:** [analysis plan](../../assets/assumption-challenger/analysis_plan_template.md) preserving faithful input restatement; mapping material claims to supported, contradicted/complicated, unaddressed or implicit assumptions; ranked lens coverage; specific falsifiable hypotheses with support/counterevidence IDs; bias hypotheses; exclusions and analysis assumptions. Preserve supported strengths rather than challenging everything.
- **Gate:** every hypothesis can change a consequential conclusion, has a source link or explicit conditional/no-direct-evidence status, and names a useful support/disconfirmation test. The plan must depend on this actual input/dossier.
- **Recovery:** request targeted research when a decisive base is too thin; return one focused clarification if the subject itself is vague. Reduce fragmentation by ranking decision value, not by an arbitrary hypothesis quota.

## Phase 3: Challenger → raw findings

- **Owns:** testing the agenda. Does not self-certify or write the final report as though verification occurred.
- **Receives:** original input, dossier, plan, effort/route and gate limits.
- **Method to use:** playbook phase 3, [analysis_frameworks.md](analysis_frameworks.md) for actual lens tests and [cognitive_biases.md](cognitive_biases.md) for input/critic patterns.
- **Returns:** [raw findings](../../assets/assumption-challenger/challenge_findings_template.md), with hypothesis/input links, precise claim, concise rationale, supporting/contrary evidence, draft confidence/basis, consequence, change condition and lens-specific fields. Preserve disconfirming/null results and cross-lens dependence or conflict.
- **Gate:** every material candidate is specific, traceable or explicitly hypothetical, and ready for all three checks. Multiple labels on one premise are not independent support.
- **Recovery:** record no material result for an empty lens; expose contradictory findings for verification; return a specific newly discovered evidence gap rather than fabricating support.

## Phase 4: Verifier → verified findings

- **Owns:** deliberate reconsideration of every raw finding. Does not claim infallibility, independence or a required downgrade distribution.
- **Receives:** raw findings, original input, plan, dossier/relevant source material, effort/route and actual access limits.
- **Method to use:** playbook phase 4 and [verification_protocol.md](verification_protocol.md), which own the conjunctive checks, dispositions, calibration, cross-lens scrutiny and repair mechanics. Consult the bias reference as needed.
- **Returns:** [verified findings](../../assets/assumption-challenger/verified_findings_template.md), retaining original and revised claims, status/confidence, all three check outcomes, counterevidence, delta reasons, split/merge links, coverage reconciliation and allowed synthesis use.
- **Gate:** every potentially delivered material finding has a disposition and justified surviving wording. No removed assertion can return as a fact. Missing body/access support stays visible.
- **Recovery:** narrow, revise, split, condition or remove; request only evidence likely to change a material result. When most critiques fail, use the smaller supported set or request a tighter plan. Preserve a well-grounded original plan when the critique was wrong.

## Phase 5: Synthesizer → calibrated report

- **Owns:** useful presentation and prioritization. Does not restore removed findings, strengthen confidence for rhetoric or execute remedies.
- **Receives:** verified findings, dossier for direct sources/dates, original input, effort/route and exclusions.
- **Method to use:** playbook phase 5 and [final report template](../../assets/assumption-challenger/final_report_template.md). Consult [example_reports.md](example_reports.md) only for calibration/shape; synthetic examples are never live evidence.
- **Returns:** a verdict of at most three sentences; smallest useful “Start here” priorities; seven substantive report areas; concrete refinements with what/why/confidence/rough effort; sources and material meta-reflections. Preserve human judgment needs, uncertainty and contrary evidence.
- **Gate:** a user can identify the useful next step, its support and limits. Every material claim maps to surviving verified wording; speculative scenarios remain conditional and supported strengths remain visible. No padding or invented action authority.
- **Recovery:** lead with exploratory limits when evidence is thin; lead with strong counterevidence when it changes the verdict; say the plan is sound when warranted. Return a bounded report or blocker rather than a fictitious conclusion.
