# Sources and tools

## Tool contract

Core work uses supplied evidence and ordinary reading/writing. Native public search or a supported browser is needed only for requested live research. A missing provider does not stop useful analysis of supplied material; it does limit claims about coverage and freshness.

For a structured standalone prospect report, Python 3.9+ is required. Resolve this skill's actual installed directory rather than guessing a relative working directory:

```text
python3 /resolved/skill/directory/scripts/revenue_report.py check /absolute/report-data.json
python3 /resolved/skill/directory/scripts/revenue_report.py render /absolute/report-data.json /absolute/new-report.html
```

Read [report-contract.md](report-contract.md) for the exact schema, return codes and limits. Use [example-report.json](../assets/example-report.json) only as a labelled synthetic example, not market evidence. The helper uses stdlib only, makes no network calls and refuses to overwrite an existing report. Successful rendering is separate from browser inspection and user access.

Choose the available supported document or spreadsheet tool for another requested format. A requested playable video, image or other production artifact needs its actual tool and separate production checks. Do not claim that Markdown describing a tool makes it installed or that a video plan is playable output.

Optional source platforms, CRM, email, calendar or publishing tools are enhancements with real access/action prerequisites. Use supported native discovery, not a shell probe that assumes Codex/Claude or scans credential stores. Do not request raw keys in chat, read browser cookies/keychain/pass stores, install providers, create persistent grants or change accounts as part of ordinary research. A subscription or connected tool does not establish unrestricted source access or permission to send.

The bundled last30days provider engine is deliberately not shipped. There is no dependency on its CLI, API keys, browser-cookie extraction, SSH route, hosted service, persistent store or scheduler. Relevant entity/date/query/deduplication/comparison/hiring methods are owned in [the local research playbook](../playbooks/research-and-customers.md). General research-library operations, paid source integrations, media acquisition/transcription and automated monitoring are not implemented here. If explicitly requested, report the missing capability and use a separately available, authorized tool only when it meets the requirement. Do not claim last30days backend feature parity.
