# In-the-Wild Variants

Current use: follow [previs method](../../methods/previs.md) and `validation-contract.md` for mode-specific timing, actual upload roles, autonomy and evidence. Version names and provider behavior in imported examples are historical, unverified here; reuse their craft without treating them as current native controls or rankings.
15 documented Previs-to-Sequence variants plus 4 adjacent single-model patterns. Use for DECONSTRUCT mode (matching an uploaded artifact to a known family) and for understanding the range of valid expressions.

## Native single-model adjacent patterns

These are not Previs-to-Sequence proper. They achieve similar outcomes with a single model and inverted workflow. Useful for routing decisions in DECONSTRUCT and for "when not to use the pattern" guidance.

### B. Kling 3.0 Smart Storyboard

Kling's "Smart Storyboard" auto-breaks a text description into multi-shot output with camera angles and transitions. Text-to-multi-shot, no external image stage.

### C. Pika V2.2 Pikaframes

Up to 5 keyframe images with per-transition prompts. Sparse-keyframe variant of the dense-grid pattern. Best when the user wants tight keyframe control over interpolation.

### D. Runway Story Panels

Runway's first-party feature generates a multi-panel sequence from a single starting image. Maintains character and style consistency across panels. Image-to-multi-shot inside one platform.

## Recognition rules for DECONSTRUCT

When the user uploads an existing storyboard and asks for prompt reconstruction, match against these features in order:

1. **Panel count and grid shape.** 8 panels = variant 2, 4, 14, or 7. 9 panels = 6, 9, 10. 12 panels = 1, 3, 11. 16 panels = 8.
2. **Subject archetype.** Dance/movement = 1, 2, 3. Combat/action = 8. Product = 5, 14. Narrative protagonist = 6, 7, 12. MV = 4, 15.
3. **Palette and aesthetic.** Bone-white on green forest = 1. Black ink on white = 2. Anime line work with food = 3. Wuxia warm = 6. Cold blue + slate = 7. Cyberpunk neon = 8.
4. **Annotation density.** Heavy 4-color arrow legend = 1, 7. Sparse annotation = 4, 14. Tabular columns = 5. Per-character colors = 8. Time brackets in HH:MM:SS = 2.
5. **Side columns.** Character sheets = 6, 7, 8. Environment map = 7, 8. Palette swatches = 1, 7.

Match to the closest variant family. Reconstruct using the corresponding Stage 1 skeleton (1 to 5) from stage1-skeletons.md. Note the delta from canonical in the output ("matches Forest Rebirth family with reduced panel count" or "matches Atlas Cloud Ranx family with single-character adaptation").
