# Build a coherent image series

Use this method when continuity is the main creative problem across related images. Decide separately whether the user wants independent prompts, a shared-session brief, or one prompt requesting a complete set.

1. Define the recurring anchor. For a character, name distinguishing face, hair, body, clothing or props. For a product, use silhouette, construction and proportions. For a place, use spatial landmarks and materials. For a design family, use palette relationships, typography and graphic rules.
2. Separate those anchors from intended variation. Wardrobe, expression, material, time, room arrangement or camera can vary if the brief asks. A variant must have a purpose, not merely new adjectives.
3. Set the series rhythm. A coherent photoshoot can maintain physical lighting, color treatment and wardrobe while camera and action develop. A controlled comparison can hold framing and pose. A product family can vary finish while keeping construction comparable.
4. Write each frame's subject state, camera/composition and distinguishing direction. Repeat essential anchors accurately in independent prompts. In a shared-session brief, put common anchors once and make dependencies explicit. In a complete-set prompt, enumerate all requested images and their differences.
5. Check the set for accidental changes, duplicated roles and missing planned frames. Keep intentional cutaways or absent subjects when the concept needs them. A common visual world does not require the protagonist in every image.

State the delivered form. Prompt count is not generated-file count; a contact sheet is one composite. If the central requirement is a single submission producing separate files, use [multi-output](image-multi-output.md) while retaining these continuity decisions. No universal eight-image ceiling belongs to series craft.
