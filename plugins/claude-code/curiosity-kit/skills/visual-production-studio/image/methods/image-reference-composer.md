# Compose references into one scene

Read every supplied image used in the composition. Assign each a job before writing the scene.

1. Make a short reference map using the host's actual attachment labels and a visible description. Roles may be identity, product geometry, wardrobe, pose, location, composition, light, material or style. Record which reference wins if roles conflict.
2. Extract only the attributes assigned to each source. A style source contributes marks, color or texture without replacing a character's face. A wardrobe reference does not donate its wearer's identity. A location reference does not imply its unwanted people belong in the result.
3. Establish one camera and one space. Place each subject at a useful scale and depth. Specify relationships such as who holds an object, which hand touches it, where feet contact a surface, and what overlaps. Resolve eye lines, perspective, occlusion and body/object contacts.
4. Give the combined scene a coherent lighting and material explanation. A relocated subject may need the setting's reflected light and contact shadow while retaining recognition anchors. Match edge treatment, grain and mark-making in drawn work instead of imposing photographic effects.
5. Choose a compact natural-language blend, role-separated JSON, or shared reference brief for multiple compositions. Include the required map in every independently copyable output. A reference map can be shared only when the deliverable explicitly assumes one continuing session.

Check both omission and leakage. Did a needed attachment lose its role? Did an unassigned face, logo, background or object leak into the composite? No universal reference-count cap or fidelity headcount comes from this method. Actual attachment limits belong to the selected model and tool.

Use [composition recipes](../references/image-reference-composer/gpt-compose.md), [fusion methods](../references/image-reference-composer/fusion-methods.md) and [Uni fusion](../references/image-reference-composer/uni-fuse.md) when their detail fits. With an output image, inspect physical integration and identity separately.
