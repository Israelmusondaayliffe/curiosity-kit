# Translate brand language into an image

Work from supplied brand material and any facts that need verification. This method is complete without Brand Studio or a strategy project.

1. Extract observable visual DNA: palette relationships, marks and letterforms, materials, finish, pattern, shape, proportion, construction and composition. Separate observations from assumptions about the brand's philosophy or actual product line.
2. Match the requested use case. A branded object, logo treatment, package, apparel concept, poster, icon, mockup and identity-board image each have different constraints. Keep exact marks and copy as supplied; flag speculative products as concepts.
3. For a focused request, develop that object directly. For open exploration, compare direct, adjacent, lateral and wild-card ideas. Explain their visual premise briefly where useful. Do not impose a ten-direction funnel or choose an accepted winner for the user.
4. Transfer the brand's recognizable relationships into the new form. Make construction and materials plausible for its medium. A brand-inspired ceramic should behave like ceramic; a retextured mark still needs readable silhouette and spacing.
5. Compose the requested image. Dark sparse boards, white studio cards, metallic treatments and premium editorial setups are optional recipes. Use the requested palette and tone rather than assuming a house aesthetic.
6. Check that brand cues survive without invented factual claims. A generated mark or package image is a concept artifact, not a guarantee of production-ready vector geometry, correct dielines or exact type.
