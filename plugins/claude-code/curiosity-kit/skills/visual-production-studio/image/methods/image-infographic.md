# Write a factual infographic prompt

Choose a visual form from the relationship being explained. Start with the audience's question and verified information, then decide whether it needs sequence, comparison, hierarchy, geography, causality, proportion or anatomy.

1. Inventory the title, labels, numbers, units, categories, connections, legend and source line. If an essential fact is absent, use an explicit supplied placeholder or [research it](image-research-prompts.md). Do not invent believable figures.
2. Select an encoding that preserves meaning. Use position and length consistently for comparisons, ordered steps for a process, containment or branching for hierarchy, and sourced geography for maps. Distinguish a causal arrow from correlation or simple reading order.
3. Describe the relationships and placement, not only object names. Bind each label to the correct element. State scale or proportionality when it conveys data, and label schematic or not-to-scale diagrams where needed.
4. Plan the hierarchy and reading path. Set information density, margins, legend location, color meanings and how annotation connects to the visual. A decorative palette must not silently change category associations.
5. Draft the prompt in prose or with a structured label inventory. In style alternatives, hold values, units, legend mapping and structural relationships fixed.

Check the draft against source facts. If a render exists, inspect numbers, labels, counts, connections and spatial relationships separately from graphic quality. An attractive chart or anatomical illustration can still be wrong.

[Infographic recipes](../references/image-infographic/gpt-infographic.md) retain diagrams, charts, maps, anatomy, flowcharts and educational posters with their full prompt forms. Dense or critical data may need a directly authored chart or diagram for exactness; explain that when it affects the requested output.
