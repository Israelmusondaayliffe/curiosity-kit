# Visual Production Studio

Choose the requested deliverable, then read the [work contract](references/contract.md) once and one complete method below. Load only the selected model profile and needed recipe/resources. A simple prompt needs no production plan, route JSON, renderer or interview. Keep exact family/version/surface and output format; model-neutral work can proceed without a provider choice. Active Sora video generation is retired; its unrelated typeface remains usable under its license.

## Image work

Use the matching complete method in [image methods](image/methods/index.md). It covers creation/editing, reference composition, camera directions and shot plans, faithful illustration/photo conversion, series, separate outputs, composite grids, storyboards, typography, infographic/layout/editorial, brand/style/time interpretation and review. Midjourney has distinct creation, edit and batch/Style Hunter operations. An image-only request never needs video resources.

## Deliver

Return the complete requested prompt, plan or actual inspected media. Check brief fidelity before craft quality. For execution report actual output state and relevant visual/audio/technical evidence; distinguish partial, blocked and unrun requirements. Preserve first failures and repair affected work. Assistant review and structural checks do not establish user creative acceptance or native provider qualification.
