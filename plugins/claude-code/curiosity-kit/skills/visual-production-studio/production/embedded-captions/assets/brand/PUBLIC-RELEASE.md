# Externally supplied Nightcity font

The source CyberpunkReplica.ttf is excluded because its available fan-kit terms restrict intended use. Preserve Nightcity/coverword only when a compatible supplied font has appropriate rights for the actual output.

Set CYBERPUNK_REPLICA_FONT_PATH only after rights/setup are authorized. Include a project nightcity-font-rights.json identifying font_sha256, license, intended_use and embedding_permitted: true. The helper checks the file/hash record; it is not a legal determination. A substituted font must match/requalify metrics.

The generated HTML embeds the font bytes. Although the helper does not copy the TTF into this skill folder, distributing editable HTML can transmit the font. Retain required notices and assess embedding/redistribution terms for that output. Private possession alone is not commercial clearance.
