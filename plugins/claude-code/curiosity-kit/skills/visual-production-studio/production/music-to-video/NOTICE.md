The Fredoka-700 payload is byte-identical to the canonical font at `../embedded-captions/modes/standard/fonts/files/fredoka-latin-700-normal.woff2`; both callers share that single payload. Its original OFL notice is `../embedded-captions/licenses/third-party-licenses/fontsource/fredoka.txt`. The recipe stager copies that font and notice into a standalone output and rewrites its reference. There is no duplicate payload in this operation.

The 66 source texture-mask PNGs are excluded from this copy because the supplied subtree lacked file-specific license/provenance mappings. The texture-flip method and its palette/timing examples remain. Supply licensed local PNG masks through the existing `frames` input and staging path; inspect the intended texture treatment before delivery. The surrounding method license does not blanket-clear replacement assets. Original source bytes remain in the private source archive.

System font stacks (Inter, Helvetica, Arial, Playfair Display, JetBrains Mono and others) are not all bundled. Their availability and permitted use must be verified in the actual renderer. Font fallback is not guaranteed pixel-equivalent. Sora typography, where present elsewhere in the production library, is a font identity and is unrelated to the retired video-generation provider.

The living-field curl-noise shader, spectral ray shader and motion recipes retain their source authorship comments. Direct WebGL preparation removes the runtime's remote Three.js dependency while keeping the shader design.
