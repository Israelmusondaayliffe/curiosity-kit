# Build one music-grounded frame

Own only the assigned frame output and explicitly assigned temporary previews. The complete manual is the approved frame block, `frame.md`, canonical audio map and selected full recipes. Read `../references/composition-contract.md` before construction. No sibling engine skill is assumed installed.

Inputs: project root; exact source stem/composition ID such as `01-intro`; frame block and track span; canvas/FPS; group treatments and role anchors; actual brand font files/colors; staged media; engine mount/readiness contract; output path. If groups are TBD, an asset is missing, the requested engine cannot mount the output, or a plan change is needed, report that specific blocker. Do not invent the missing plan.

1. Read each chosen HTML's full head/body/styles/scripts. For recipe-only primitive IDs read `../references/catalog-recipes.md` and its implementation. Preserve helper functions, shader source, filter definitions, type styles and assets; do not extract only body markup.
2. Convert every track timestamp to local time by subtracting the frame start. One finite paused master timeline spans exactly zero through frame duration. Group containers show/hide with 0ms state changes across their own local intervals. Root owns BGM and final frame transitions; this frame is silent unless expressly assigned otherwise.
3. Author a self-contained engine-compatible frame. For engines using template subcompositions, wrap `#stage` and owned styles/scripts inside a template, set data-composition-id to the filename stem, and register the same timeline key. Use the engine's verified contract rather than assuming every renderer consumes this format. Load one host-owned GSAP, not per-group copies.
4. Scope every ID, class selector, style reset, CSS variable, SVG reference, helper and shader/canvas instance. Never rewrite document/body state from a group. Duplicate copies of the same effect must remain independent. Prebuild display nodes; ordinary text uses textContent. Inert supplied SVG follows the contract's parser allowlist.
5. Prepare fonts and textures before measuring/building. Keep font-ready and asynchronous engine initialization explicit. Compose all field/text/blur hooks in a frame-owned dispatcher. After each time evaluation run every relevant hook once; suppressing GSAP events must not suppress the actual repaint. Dispose resources on unmount.
6. Bind brand tokens and real score anchors. Source demo constants are examples, not current audio timing. Preserve useful easing and percussive cuts. For portrait/square adapt line breaks, safe margins, layout and shader dimensions together. No blind anisotropic stretch.
7. Validate frame zero, group boundaries, readable holds and final state. Every late ring/tail must fit the approved frame; rescore deliberately rather than lie about metadata. Restore reversible operator state and remove demonstration resets when the intended shot ends on a hold/exit. Phrase-flow groups do not acquire beat-cut choreography.
8. Return the exact output and a concise dependency/readiness/qualification summary. A local parse check is not engine render proof. Do not run assembled-project commands against a lone frame. The orchestrator integrates all frames then runs engine/media QC and sends only affected findings back.

Terminal checklist: file stem = composition ID = timeline key; exact duration; no unowned audio; local assets resolvable; chosen font really loaded; no duplicate visible spectral word; callbacks compose; instance scope intact; cold/reverse/repeat checks either evidenced or specifically unrun; full original effect retained.
