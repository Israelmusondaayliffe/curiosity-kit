# Leonardo image families

Evidence checked 9 October 2026. Guide-backed Lucid product craft and Phoenix API/reference guidance. Lucid Origin, Lucid Realism, Phoenix 1.0 and Phoenix 0.9 remain separate targets.

## Lucid Origin and Realism
Start with a short subject-first description, then use selective lighting, lens and typography cues to control the result. Add useful constraints rather than a long undifferentiated style list. Origin and Realism are not interchangeable labels. A guide suggesting trying another model is not authorization to override the selected one.

Authored Origin prompt: “A sculptural cobalt-blue perfume bottle, centered on pale sand, hard side light, crisp shadow, clean editorial product photograph. Small white label reading ‘TIDE’.” Keep the visible label and shape consistent during one-variable iteration; inspect lettering rather than promise it.

## Phoenix 1.0 / 0.9
Bind character, content, image-to-image and style references to their separate intended roles. Record whether prompt enhancement is enabled when exact authored language matters. Do not copy Phoenix native fields or reference weights into Lucid. Generic negative-prompt advice requires exact endpoint verification. Public-feed or visibility settings need explicit attention; they are not a harmless creative default.
