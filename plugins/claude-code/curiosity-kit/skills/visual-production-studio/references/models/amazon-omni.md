# Amazon Nova 2 Omni

Evidence checked 9 October 2026. Catalog/schema-backed discovery, not a specialized image prompting adapter. This is a distinct multimodal conversational image-output surface; do not substitute Nova Canvas or inherit its negativeText/mask controls.

## Useful authoring without invented controls
Maintain the conversation's visual task and references: say whether to create a new image or modify a supplied one, then give the visible change and preservation priorities. Keep the user's exact text and refer to the actual attached image. Before execution, resolve the model and request/response content types from its own schema.

Authored generic instruction: “Using the attached kitchen image, make the cabinet doors sage green. Preserve the room layout, worktop, appliances and daylight.” The wording is an ordinary edit brief. This survey does not establish that every Omni endpoint supports that edit, or a native mask, seed, batch count or reference limit.
