## Preserve V7 and choose the operation's grammar

V7 is a retained image-model selection, not Video Model V1. Its creation/reference/personalization compatibility must be taken from the V7 row and relevant current guide; V8.1/V8.2 or Edit compatibility cannot be copied backward. Global V7 personalization and newer V8 profiles have different compatibility. Existing V7 style codes and requested historical snapshots remain intact even when a later version is available.

Authored V7 creation example: `a tiny brass observatory on a snow-covered hill, blue dusk sky, warm light in the dome, miniature architectural photograph --ar 3:2 --v 7`. The visible scene comes first; native selected-version controls trail it. For V8.2, keep the user's selected version and only use controls supported by that row. Do not append quality, multiprompt weights or Omni merely out of habit.

For Edit, write the transformation: “Replace the linen upholstery with deep-green velvet; preserve the chair's outline, wooden legs, view and room.” Web references occupy the actual attachment roles; Discord edit uses its documented --edit URL form. Image Prompt weighting (--iw), Style Reference weighting (--sw) and Edit references are separate semantics; do not invent Edit weights. Preserve source URLs/codes/profile IDs exactly.

Retain the image method's eleven edit recipes, staged edit chains, thirteen failure-repair classes, layer/inpaint/outpaint operations, Explore/Create prompt reuse and selected HD lineage. Their procedural instructions live in [Midjourney edit](../../image/methods/midjourney-edit-architect.md), [creation](../../image/methods/midjourney-prompt-architect.md) and [batching](../../image/methods/midjourney-prompt-batching.md); load only the requested operation.
