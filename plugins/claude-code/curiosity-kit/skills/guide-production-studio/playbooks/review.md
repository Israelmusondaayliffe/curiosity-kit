# Review the actual guide

Read the delivered artifact before the author's rationale, record or self-grade. Choose depth proportionate to the job. Ordinary writing can finish with an honest author check; independent review and real learner observation add different evidence when available.

## Attempt the reader's path

Start with only the stated prerequisites and supplied material. Locate the first action and attempt it in a safe isolated setting when possible. Record the first point where you must guess, leave the guide or infer a missing term. If you only simulated the path by reading, say so; do not call it execution or a cold-reader study.

Trace each consequential claim, example fact and answer against its source. Check applicability, permission, required attribution, uncertainty and execution status separately. Inspect the actual outputs rather than trusting “tested” labels. An authored illustration can be useful without being observed evidence.

Review these ten original dimensions together; a high score elsewhere cannot cancel a critical failure:

1. **Purpose:** the promised finish is clear and actually delivered.
2. **Context:** the reader knows why and when to use the method, including its limits.
3. **Vocabulary:** necessary terms are grounded before use without removing precision.
4. **Action:** inputs, prerequisites, steps, expected result and finish are complete.
5. **Evidence:** factual/performance claims have applicable support; unrun examples are honest.
6. **Provenance and privacy:** permitted public lineage is retained; private details and unauthorized reuse are excluded.
7. **Examples and reuse:** completed examples, useful variation and reusable material serve the task.
8. **Troubleshooting:** concrete symptoms lead to diagnostic actions, repairs or a justified stop.
9. **Structure and visuals:** navigation, reading order, visual meaning and accessibility work in the delivered format.
10. **Voice and value:** clear adult language, useful specificity and appropriate tone survive editing; no generic filler replaces expertise.

For workshops, attempt each access branch and inspect separate presenter notes. For prompting guides, inspect conflict resolution, source boundaries, output labels, alternative valid answers and targeted repair. For revisions, verify changed facts propagated without damaging untouched material.

## Distinguish checks and decisions

- Author self-check: the writer inspected its own artifact.
- Independent cloud reader: a separate reader received the actual artifact/task; retain its real output and conditions. A different name in JSON is not evidence of independence.
- Human cold read: a real intended reader paraphrased or attempted the task; record actual observed confusion/results with permission. Model predictions are not human observations.
- Structural/helper check: records, links or files met mechanical conditions. It does not prove meaning, privacy, rights, teaching or layout.
- Rendered inspection: actual rendered pages/screens were viewed; identify what was seen. Source inspection alone is not rendering.

Before producing a family or bulk set of guides, finish one representative artifact, obtain the user's decision (or the independent/human review they specified), repair it, then scale only within that approval. Skip this gate only when the user explicitly waives it. Do not manufacture approval or impose the gate on a single ordinary requested guide.

## Repair the smallest real defect

Classify a problem by consequence, not a prose score. A missing essential input, unsupported consequential fact, private disclosure, impossible access branch or absent required visual can block the affected deliverable. Stylistic preferences usually do not. State the exact location, observed problem, why it matters and smallest repair.

Use the write/revision route for repairs, including local clarity and adult explanation. Reinspect the affected path and dependencies. Keep the original finding and changed artifact distinguishable; a failed attempt is not erased by a later pass. Avoid new frameworks or broad reruns when one affected check is sufficient.

Deliver the finished guide and a concise factual handoff: what was checked, what remains unverified and any user decision needed. “No critical defect found in these checks” is bounded; “certified usable” is not. Optional [evidence records](../references/evidence-contract.md) can keep a substantial review traceable without burdening the participant artifact.
