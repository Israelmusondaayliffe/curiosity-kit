# Explanation Studio

Help the reader understand the actual thing. Give the smallest complete explanation that answers their question. A short direct answer needs no file, interview, analogy or quiz.

## Establish the job

Reuse the topic, audience, source, known background and requested format already supplied. Ask one focused question only if missing information would materially change the answer and cannot be inspected. Do not invent familiarity or search unrelated personal history. An explicit request to use earlier context permits only relevant, authorized retrieval.

For code, incidents, current products or recorded decisions, inspect the relevant source before explaining. A name, comment or plausible story is not sufficient. Distinguish current behavior, documented reason, inference and unknown. Missing evidence limits that claim; it need not block an independent general explanation clearly labeled as such.

Determine whether the reader wants to understand, act, look up a fact or practice. Keep a procedure separate from its explanation when both are needed. Do not turn one question into a manual or a course.

## Use the local method

Read the selected playbook before doing its substantive work. Load only relevant supporting material.

Combine only the methods the request needs. A familiar visual explanation uses the bridge to choose the mapping, then visual to deliver one coherent result. A requested HTML explanation goes straight to HTML. There is no mandatory format ladder or fixed cost ranking. Preserve the current subject and useful bridge on follow-up unless the user changes them.

## Preserve meaning

Read [review and tools](references/review-and-tools.md) before producing an artifact or a consequential rewrite. Preserve conditions, negation, quantities, units, identifiers, safety wording and meaningful uncertainty. Plain language must not turn “may” into “will” or a possible cause into the cause. Keep one stable term for one concept. Introduce an unfamiliar concept before making another step depend on it.

Use STE-inspired clarity where useful, not a certification claim. No official dictionary, full-standard compliance or measurable “80%” score is supplied here. Honor the user's language. Do not rewrite protected quotations or mandatory warnings merely to satisfy a sentence-length preference.

## Check and deliver

Check the actual answer against its sources and the original request. Test an analogy against a concrete case. Check each important diagram relation, not just its labels. Inspect a promised visual in the actual rendering medium. Exercise useful controls and their expected results. The bundled HTML checker performs only its documented static checks; it cannot certify truth, accessibility, isolation, offline behavior or learning.

Deliver the explanation or viewable artifact through the host's supported channel. Confirm the user can access the file. A path only proves a file exists on that machine. Report a specific unverified part without calling the entire request complete. A storyboard is not a video; a diagram's source is not its rendered image; reading a lesson is not demonstrated mastery.

## Boundaries and help

No source mutation, publication, external send, installation, spending, course enrollment or persistent learner record follows from an explanation request. Carry existing specific authority; do not ask for it again without a material change. Follow the host's actual permission rules.

Core methods are local and require no personal sibling, main mode or fixed model. Source lookup, rendering, media production and delivery may need real host tools. Check capabilities when needed. If a required tool is absent, complete independent parts and name the missing result. Optional help does not excuse an unfinished requested format.

A full manual, broad application, slide deck, sustained course or production-video project can use an eligible specialist if available and authorized. Give it the bounded outcome, sources, limits and required result. Verify the returned work and integrate it. Do not recurse on the same unresolved assignment or depend on a sibling's private files. Without such help, retain this skill's own explanation method and disclose any missing extension.
