# Acting and performance

Inputs: current scene, approved character/voice descriptions, physical conditions and any supplied performance evidence.

## Direct behaviour

Keep one master behaviour paragraph and one stable voice description per recurring character. The master names body history, balance, tempo, posture, habitual movement, a triggered gesture, what is concealed, the social mask and what breaks it. Eye behaviour includes gaze target, focus changes and blinking; it is not a demand for perpetual staring.

Adapt the master to each scene. State whom the character wants to influence, what blocks them, what they risk, their opening tactic and what causes a tactic change. Give physical business, distance and status a reason. Transfer a characteristic into a physically possible form: a habitual pacing rhythm might become finger pressure on a chair arm when seated. Do not paste a walking performance into a seated shot.

Write observable states and purposeful actions rather than naming feelings or vague transitions. A line's meaning can differ from the action underneath it. A listener reacts only after perceiving the cue. An early reaction may begin during the speaker's line, but not before the information exists. Preserve intentional stillness, delayed reaction and uneven group responses.

The exact approved voice description accompanies each speaking character. Dialogue belongs in the audio block only; performance action does not duplicate spoken words. Silent cast remain explicitly silent. A new vocal delivery may change pressure or tempo while retaining identity.

### Diagnose performance before adding adjectives

| Visible symptom | Useful correction to test |
|---|---|
| Fixed stare | Give a meaningful gaze target and a specific refocus cue. |
| Emotion label with no behaviour | Replace it with an objective, tactic and physical consequence. |
| Face moves while body floats | Specify weight, support and the contact carrying the action. |
| Everyone reacts together | Assign each observer a different cue and response timing. |
| Listener waits like a statue | Add a perception/assessment beat when the information arrives. |
| Busy random gestures | Keep one action that serves the immediate objective. |
| Repeated decorative gesture | Tie it to a trigger and omit it when that trigger is absent. |
| Immediate reset after a serious event | Carry the changed breath, posture or task into the next beat. |
| Monotone line | Mark the conversational tactic and the word carrying the pressure. |
| Voice changes between shots | Restore the approved voice description and inspect actual audio. |
| Impossible posture | Adapt the behavioural intention to the available position. |
| Mouth movement on a silent character | Bind exact speakers and require the remaining cast's silence. |
| Action outruns its cause | Reorder the cue, assessment and action. |
| Unmotivated camera-facing pose | Give a partner or object as the attention target. |
| A beat contains incompatible actions | Split it at a visible end state or remove secondary business. |

Use a 0–5 acting review as a judgment aid: 0 unusable, 1 severely contradictory, 2 readable but artificial, 3 credible with a named defect, 4 purposeful and responsive, 5 unusually precise. Important close-ups aim for 4 or higher; at 2 or below, rewrite the direction before another attempt. Report the observed evidence and reviewer, not a score alone. No rendered performance means no rendered-performance score.

## Output and repair

Return one scene adaptation per active character: objective, obstacle/stakes, tactic and visible beat changes, subtext, physical/gaze/listening choices and the locked voice. Put that adaptation in the shot acting field; put exact lines only in audio. Before sending, check causality, feasible posture, identity/voice continuity, distinct ensemble responses and the scene objective. Inspect actual media before scoring performance. Repair one causal instruction, preserve the other choices, then recheck through the [bounded review](review.md).
